## Single-definition rules

The schema enforces D1–D6 (doc 07 §5.2): defaults stated once (D1), unique keys
(D2), unique CLI flags disjoint from reserved names (D3), 1:1 description msgids
(D4), unique placement orders per screen section with known screens (D5), and one
entry per product-decision slot (D6).
