# Worklog archive

- The live, append-only shared log (AGENTS.md §4) is always repo-root `worklog.md`.
- Archives are never edited after creation — append-only discipline applies to them too.
- Archive convention: one file per ~phase cluster, or whenever the live log
  passes ~1 MB — whichever comes first.
- `archive-2026-10.md` — 10,945 lines, 1.68 MB; Wave 1 through Wave 7,
  phases 0–8 (bootstrap, planning, engine, UI, gates, closure, hygiene prep).
