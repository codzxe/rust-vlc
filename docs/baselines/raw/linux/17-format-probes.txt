# 17 — Format-selection probe sessions, consolidated (Task 0.B4-R)

Oracle: pinned VLC 3.0.23 Vetinari (3.0.23-2-0-g79128878dd), Linux x86_64,
extracted Debian debs at tmp/pinning/extract/ (see dumps 01-11). Clean-room:
fixtures are OUR OWN synthetic files (pure-Python struct writers, gen_py.py,
preserved at probe-work/gen_py.py; ffmpeg lavfi/encoder synthesis for the media
fixtures — the exact ffmpeg command lines were NOT preserved by the prior 0.B4
session [VERIFY]; per-file content below was re-derived 2026-10-19 with ffprobe
on the still-present tmp/probe/media files, plus x265 remnants in gen_hevc.err /
gen_mp4hevc.err). Oracle behavior observed via -vv debug logs only. No VLC
source consulted. Media fixtures are NOT committed (gitignored tmp/).

Harness (probe-work/run_probes.sh, verbatim semantics):
  EXTRACT=/home/z/my-project/tmp/pinning/extract
  export LD_LIBRARY_PATH=$EXTRACT/usr/lib/x86_64-linux-gnu
  P=/home/z/my-project/tmp/probe
  VLC="$EXTRACT/usr/bin/vlc -I dummy --play-and-exit --aout dummy --vout dummy -vv"
  run() { timeout 25 $VLC "$@" > $P/logs/$name.log 2>&1; echo "$name exit=$?" >> status.txt }

The logs directory holds 61 .log files + status.txt (57 status entries).
Present here: all 61, in probe order. The four without status.txt entries are
smoke_wav (pre-status smoke run), http_server (python http.server daemon log,
server side), rtp_ffmpeg + udp_ffmpeg (0-byte sender-side capture attempts).

Decisive-line extraction pattern (verbatim rg output below, one block per
probe; constant noise annotated once here): every local-file session logs
`using access module "filesystem"` for the media-library ml.xspf load, a
`using demux module "directory"` line for the playlist/directory preparse, and
XSPF media-library export lines at shutdown — those belong to the harness, not
the fixture. The per-fixture decision lines are the demux/packetizer/decoder
selections that follow, plus the probe-specific debug lines included below.

Exit codes: 0 for all status-tracked runs except rtp_ts (124 = timeout on a
live stream, decoding still observed). Plugin-load warnings about libpulse/
vdpau/xcb .so files are extraction artifacts (headless debs excluded), do not
affect module selection for the probed families.
