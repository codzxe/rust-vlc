# Lumen 0.1.0

Release tag: `v0.1.0`

This is the first tagged release of Lumen, a clean-room,
from-scratch reimplementation of a VLC-class media player: a 100 %
Rust media engine (playback state, probing, demuxing, decoding,
filters, A/V pipelines, synchronization, streaming, devices,
playlists, subtitles) with a React + TypeScript UI and a wasm32 web
build of the same engine.

## Scope (honest — read this before installing)

What this release actually does, per `docs/feature-matrix.toml`
(recomputed 2026-11-10, `docs/audit/docs-sweep-20261110.md` §4.3):

- **37 of 73 format rows** are claimed (implemented or partial) on
  desktop: 14 containers, 6 video codecs, 9 audio codecs, 8 subtitle
  formats. **Zero rows are claimed for the web build.**
- The `lumen` CLI is the real engine surface in this release —
  headless decode, playback state, seeking, A/V sync. Audio output is
  the ADR-005 null device (real output adapters exist as seams but no
  backend is admitted yet).
- `lumen-desktop` is the ADR-004 std-only composition-root skeleton —
  it opens no window; it ships so packaging paths are exercised
  honestly. The Tauri webview shell is infra-blocked (issue #4, R-04).
- No release has existed before this one; there is no upgrade path to
  test and **no update mechanism ships** (the MSI's frozen UpgradeCode
  makes future MSIs replace this one rather than co-install).

## Known limits (honest)

The full register is `docs/KNOWN-LIMITS.md`; the release-process
register is `docs/RELEASE.md` §"Known limits (honest register)". The
headlines users will hit:

- **Binaries are unsigned.** No Windows code-signing certificate, no
  Apple Developer ID / notarization (external procurement blockers,
  tracked in the wave program). Windows SmartScreen will warn; macOS
  Gatekeeper requires right-click → Open.
- **Audio output is not admitted yet** (ADR-005): the CLI decodes and
  syncs, but the audio backend is the typed null device — see
  KNOWN-LIMITS §4.
- **The desktop binary opens no window** (ADR-004 skeleton; Tauri
  shell infra-blocked).
- **Web build: zero claimed rows** — the wasm engine exists and is
  smoke-built (`scripts/rc-smoke.sh` check 6), but no format is
  claimed on web.
- **No updater, no telemetry** (all telemetry settings default OFF).
- Linux arm64 artifacts are best-effort (hosted-runner availability;
  the job is continue-on-error).
- "All formats supported" claims of any kind are prohibited
  (KNOWN-LIMITS §8, R-26) — the feature matrix is the authority for
  what works.
