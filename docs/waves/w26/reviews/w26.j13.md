## Dimension scores

### 1. Token discipline — **9/10**

Every color/size/spacing in the seven area sheets flows through
`var(--semantic-token)`; raw hex appears only inside comments and
`/* frame: <Frame.svg> */` markers (e.g. hotkeys.css:31, extensions.css:31-32,
subtitles.css:83) — contract §4.4 compliant, and the eslint
`local/semantic-tokens-only` rule is active (eslint.config, 0 errors). The
frame-disabled dim rides `var(--opacity-muted)` (staged.css:33-35), the exact
token (0.3). The two inline styles are computed/dynamic values (subtitles
swatch = row DATA, not a theme color — correctly justified in-file at
subtitles.tsx:258; tick offsets are arithmetic). Only deductions: staged.css
frame-arithmetic margins (8.5/10.5/12px) are raw px with frame citations but
no `frame:` marker on two of them (staged.css:52,58 say "frame:" in the
comment — fine, but :44 `margin-bottom: 0` carries none; trivial), and
subtitles.css:148 documents an ink (#1A1611) mapped to `--color-surface-muted`
with the Δ5/255 derivation honestly recorded. Near-exemplary.

### 2. CSS architecture — **8/10**

stylelint standard: **clean** (real run). No `!important`. No dead rules
found — every selector in staged.css/controls.css/extensions.css resolves
against live section ids (verified against each area's DOM: library
opening-files/metadata-artwork, network buffering/proxy/security, recording

## Overall

- **Mean: (9 + 8 + 7 + 8 + 8 + 6 + 7) / 7 = 7.6**
- **Verdict: KEEP** — with a named post-wave refactor list (findings 1, 3-6).

This is disciplined, unusually well-documented code carrying a hard design
constraint (never fake a live control) that it honors consistently across
all 13 areas, with tests that pin the honesty rather than the pixels. The
systemic weaknesses are wave-shaped, not care-shaped: the parallel-lane
protocol manufactured ten copies of the seam hook and four staged-row
families, and the i13/i14 ⓘ census stopped one area short. Both are
one-lane cleanups for the Lead. The single P1 (performance's ten invisible
ⓘ) is the only user-visible defect, and it is an absence, not a lie — which,
in this codebase, is the difference between a 7.6 and a 5.
