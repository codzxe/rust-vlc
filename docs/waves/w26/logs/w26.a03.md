## 2. Defect found & fixed (the one real gap)

**Primary play pill rendered a GRAY glyph** (`#8f8f8f`) instead of the dark
on-accent triangle: `icon.css` paints `.lumen-icon` from
`--color-stroke-icon`, which shadows the button's `color`. VLM iteration 2
caught it; pixel sample `(79,215) = (143,143,143)` confirmed. Fix (button.css
only): remap `--color-stroke-icon` in-subtree per state — base
secondary→bright on hover/active/focus-visible, primary = on-accent at every
state (guard rule at (0,2,0) for the pseudoclasses), tinted = accent→bright→
strong, disabled = tertiary. Verified live: primary label+glyph both
`rgb(9,9,9)` at rest AND hover; default hover label+glyph `rgb(234,234,234)`
on `#262626`. Regression test added in `Button.test.tsx`.
