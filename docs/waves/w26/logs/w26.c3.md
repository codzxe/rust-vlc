## Decisions & notes for the Lead

- **Selector is lane-scoped**, not the shared Dropdown — the frame's
  two-tone mode previews are custom svg nodes. When the menu lane lands the
  additive `icon?: ReactNode` API (c1's ask), the selector can migrate; the
  grammar/interaction parity is already 1:1 (only typeahead omitted, 5
  options).
- **Open-list anchoring**: trigger retained + list 4px below (a19 primitive
  grammar + c1 EQ-presets precedent). The frame's literal open state
  replaces the trigger with the list — documented deviation.
- **Display scale** (64px well, 3px bars, 2× the icon grammar, resting =
  each mode's own icon geometry, spectrometer ring math) is house-chosen —
  the frame measures only the 20px icons [VERIFY with Lead / engine lane].
- **eq token group** for live spectrum bars = the mission's "eq/accent
  token groups" pin (W25: "equalizer band/level accents"); two-tone
  content-secondary/accent-strong everywhere the frame paints two-tone.
