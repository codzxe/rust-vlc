## What I built

route (CONTRACT §3 "No direct frame" row), so the screen is composed from the
design language (§2) with the three nearest grammars:

- **playlist.png / playlist.svg** — row anatomy (icon · title · meta ·

## Decisions

1. **Left-anchored column** (Settings - *.svg content grammar), not centered —
   working-screen density, the shell main region scrolls.
2. **Section headers OUTSIDE the cards** (Settings column-edge grammar); the
   cards hold rows/prose only. Avoids header/row-text alignment gymnastics
   and keeps each `<section>` landmark properly labelled by its h2.
3. **Empty state split** into title + body for the ListEmpty grammar — new
   keys `discovery.volumes.empty-title` / `discovery.volumes.empty-body` in
   `ui/src/i18n/keys/w26.b12.ts` (lane seam resolver `useDiscoveryMsg`, same
   pattern as w26.a10/a12; all other copy reuses existing `discovery.*` keys).
4. **Rows panel 8px padding / prose panel 12px** — ListRow carries its own
   20px frame insets (playlist.svg icon lands ≈28px from the card edge ≈ the
   frame's 27px); prose gets one step more inset for the r14 corners.
