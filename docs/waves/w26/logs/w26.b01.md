  (`SettingsSections`): 784×38 r2 `surface-panel`@95% bar, label + ›/∨
  chevron (chevron-right/chevron-down icons) centered, `aria-expanded` +
  `aria-controls`; `advanced: true` schema entries render BELOW the bar when
  open, flat, no headers (global-1.svg). The bar renders only where advanced
  entries exist (global.svg has it; interface/controls.svg frames do not).
  The old per-field "Advanced" badge is gone (redundant with the
  disclosure); the restart badge stays (behavior contract).
- **Apply/Revert bar** kept (no frame shows it — pitfall 2), restyled: sticky
