## What was built

### `ui/src/theme/lumen.css` (NEW — replaces solstice.css, deleted)

Layers (colors/fonts are 100% semantic `var(--…)`; raw values are geometry
only — 1px hairline, 8px scrollbar gutter, 1.5 line-height):

1. **Root type** — `html { font-family: var(--font-family-sans);
   color-scheme: dark }` (+ `light` variant), `body` paints
   `var(--color-surface)` / `var(--color-content-primary)`, font-size
   `var(--font-size-body)` (10–15px scale), `line-height: 1.5`; headings
   semibold with −0.01em tracking. No bundled `@font-face` (the Nunito
   face lived in solstice.css and is gone with it).
2. **Numerals** — `.tabular, .timecode { font-variant-numeric:
   tabular-nums }`.
3. **Scrollbars** — `scrollbar-width: thin; scrollbar-color:
   var(--color-stroke-border) transparent` + Chromium pseudo rules
   (8px, transparent track, stroke-border thumb, 4px radius). Resolves to
   the spec's `#404040` thumb once the W25 token set lands.
4. **Selection** — `::selection` orange-tinted via
   `color-mix(in srgb, var(--color-accent) 32%, transparent)`.
5. **Focus floor** — `:focus-visible` 2px `var(--color-accent)` ring
   (same declarations as `a11y/focus.css`, which stays; duplicated so the
   base sheet alone is keyboard-legible).
6. **Primitives** — `.lumen-panel` (surface-panel bg, 1px stroke-border,
   `var(--radius-panel)` = r12–14 card grammar), `.lumen-row` (flex row,
   `var(--radius-inset)` r6, neutral layout only), `.lumen-separator`
   (1px hairline).
7. **Reduced motion** — global `prefers-reduced-motion: reduce` block
   (animation/transition ≈0, `scroll-behavior: auto`).

NO sunset/tape/keycap/Nunito/`data-backdrop` remnants (verified: served
CSS has zero `@font-face`, no `[data-backdrop` selectors from this sheet).

### `ui/src/theme/ThemeProvider.tsx`

  documents orange as the product default). Renders correctly with BOTH

### Vision verdict analysis (why GAPS is not actionable in this lane)

The reported gaps — warm-brown app bg (≈#241d13), cream text, Nunito-feel
type, warm glow band at the bottom — are all **stale Solstice token
VALUES** (`--color-surface`, `--color-content-*`, `--font-family-sans`
still carry the 2026-11-08 warm set) plus screen-CSS remnants (player /
onboarding / appshell sheets still carry `.solstice-*` rules and their own
warm gradients — their lanes own those files). My layer paints purely via
`var(--color-surface)` etc., so it flips to near-black `#090909` + Inter
the moment the token lane's regenerated `tokens.css` lands. Nothing
further to iterate in this lane until then.
