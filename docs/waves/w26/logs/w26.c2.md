## Decisions (frames win)

1. **Plain values, not chips**: the mission parenthetical says "value chip
   right", but all three frames are the PLAIN-value family (analysis §A4
   note: chips are the EQ family A1/A2). Frames win — plain `#6B6B6B`
   right-aligned values; documented here for the Lead.
2. **"RMS / Peak"**: frame says "FM5 / Peak" — design typo corrected per
   analysis §A4/§D4.
3. **Card r6** (analysis correction 1) — this lane ships r6
   (`--radius-control`), diverging from a18's r8 ToolsCard intentionally;
   a18's shell is untouched (their file).
4. **Staged display ranges**: ranges are calibrated so each frame default
   renders at the frame's SVG-measured thumb position (e.g. threshold
   −30..0 puts −11 at 63.3% = frame fill 207px; widener 0–0.9/0–0.8/0–1.0
   reproduce fill 72/122/263). Engine ranges replace them on wiring —
   noted in `types.ts`.
5. **Toggle labels reused** from w26.a18's pre-registered keys
   (`player.tools.expand/collapse-settings`) via the seam-first resolver
   (`copy.ts`, a17 pattern) — no duplication across key files.
