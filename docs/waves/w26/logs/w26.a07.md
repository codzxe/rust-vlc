## 2. Geometry conventions (unchanged from committed lane)

24×24 viewBox, no rescaling — paths translated so each bbox centres on (12,12).
Shell stroke = 1.5 `currentColor` (`--color-stroke-icon`), emphasis variants
2/3 (`--stroke-icon-strong/-max`). Design-filled shapes carry
`fill="currentColor" stroke="none"`. Per-element sheet stroke overrides kept
verbatim (info stem/dot 2, speed/wrench needle 1.28571, list rows 1.28571,
more dots 3). Known documented deviation: Figma "inside"-stroke mask bodies
(file/home/sidebar) use centred 1.5 stroke, shape-identical.

## 3. Icon Wrapper (design/figma/Icon Wrapper.svg, verified this run)

Frame geometry re-measured from the SVG: hover backdrop = 30×32 rx **4**
`white @ 6%` ("Property 1=hover"); Default = bare icon.
- `sm` 24×24 dense rows · `md` 30×32 (the frame itself) · `lg` **44×44**
  (contract ≥44px rail hit target).
- Hover/focus-visible → `--color-surface-hover` backdrop (token carries the
  frame's white-6%-on-#090909 intent); bare at rest.
- `active` → `.lumen-icon-wrapper--active .lumen-icon { color:
  var(--color-accent-icon) }` = the ONE orange accent (#d37918 pipeline).
