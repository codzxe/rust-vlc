# w26.a01 — tokens lane (design-token source of truth)

Wave 26a · 2026-11-11 · Owner: w26.a01 · Log for the Lead.

## Mission (task brief)

Own `themes/tokens.json` + the token pipeline: re-pin the semantic layer to
the W25 spec §1 measured values, make ORANGE the default accent and align the
9 swatch hexes to the design set, move font groups to the Inter stack (kill
Nunito), remove the Solstice-only groups (sunset/note/tape/keycap + their
exclusive warm primitives), add an `eq` semantic group (7 band accents,
`/* frame: EQ.svg */` provenance), regenerate
(`npm run tokens:generate` + `tokens:check`) and keep `src/tokens` tests
green.

## Decisions

1. **Accent ids kept** (`cyan`/`violet`/`pink` not renamed to
   teal/purple/magenta): `AccentId` is a frozen public type consumed across
   lanes; only hexes + order + default changed. Design-facing label naming is
   the settings/i18n lanes' call.
2. Orange ramp = mined file ramp (ramp_from_file path), so the default
   accent's strong/bright/tinted are exactly the spec's #ab6314/#e8851a/#371f06
   (+#d8ba9a light tint); alternates use the crate derivation.
3. `content.tertiary` became per-mode (dark #6b6b6b / light #9a9a9a) — the
   single-value trick doesn't survive the neutral ramp; light block gains one
   decl.
4. `stroke.icon` dark re-pinned to #8f8f8f (measured icon color; the old file
   had it share content.primary).
5. Font sizes/weights kept (doc-08 cap-height scale, same corpus); the W25
   10–15px compact scale is applied per-screen by the screen lanes.
   Blur/opacity/motion/space/stroke-width kept (measured, not Solstice).
6. Light surface trio (#f0f0f0/#f5f5f5/#efefef) are spec-pinned though the
   light frame literally paints #D5D5D5@0.75 / #E7E7E7@0.8 — spec wins
   (contract §0); translucency stays in opacity.panel/chrome.
