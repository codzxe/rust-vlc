## 2. This session's 6 residual deltas (found by the audit loop, fixed + re-verified)

1. **Gamma slider missing its 9 degree ticks** — spec comment documented them but
   the entry omitted `ticks` (vision flagged "no ticks on Gamma"). → `ticks: 9`
   (frame x737.6–990.4 pitch 31.6 = the (i+1)/(n+1) spread). DOM: 9 ticks.
2. **2px orange focus ring on the sidebar's active row on EVERY load** — the f03
   mount-focus (focus starts on the active row) matches `:focus-visible` in
   Chromium before any user interaction, so screenshots/users saw a ring the
   frames don't carry (flagged by both vision runs). → `data-mount-focus` marker
   + `[data-mount-focus]:focus-visible { outline: none }` + first-keydown
   capture listener clears it (keyboard users keep the ring; the e2e tab audit
   passes through — its first Tab clears the marker before asserting). DOM at
   load: `outline: none`, bg #222222, icon orange intact (PIL: 47 orange px,
   all inside the 18px icon box).
3. **Float rows rendered "0" vs frame "0.0"** (Replay gain preamp) — float rows
   now render a formatted text well (`formatFloatValue`: one decimal minimum,
   natural beyond; schema range clamped on parse). DOM: "0.0".
4. **Subtitles/interface trailing-scroll** — bottom padding (24px) + last
   section margin (28px) invented 52–60px of scroll past the last control
   (subtitles scrollHeight 875 > 815 with all rows already visible). → padding
   `33px 24px 0`, `.settings-sections .settings-section:last-child` + its last
   row margin 0, area-scoped 2px/interface 5px per-boundary reclaim (both
   screens were 1.5–5px over the fold). DOM: both **815 == 815, zero scroll**.
5. **Library sidebar glyph** — frames pin the FOLDER glyph (global.svg
   "setting category_9" = the Icon.svg folder sheet's Vector 23 shape; vision
   flagged twice); live used "lists". → `AREA_ICONS.library = "folder"`.
6. **"10 s" vs frame "10s"** — the hide-after scale's right label is space-less
   in interface.svg (y741). → frame-verbatim "10s".
