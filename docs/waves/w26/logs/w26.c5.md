## What was built

   stacked v0 widgets (master volume, mute, balance, 3-band EQ + 4 video
   adjust PendingSliders) are REPLACED by the frame's Effects section: the
   "Equalizer" enable toggle row (staged OFF), the **wave-c EqualizerTool
   embedded full-width and EXPANDED** (the frame's EQ block; its built-in
   presets panel covers the frame's "Equalizer preset" row), then Two-pass /
   Spatial audio / Spatial audio mode (dropdown, frame value "Headphone
   virtualization") / Stereo widening — every row staged per the old
   pattern: disabled-with-reason note + `data-pending-command`
   (`audio.set-eq` / `audio.set-spatializer` / `audio.set-stereo-widener`,
   the c2 forward declarations). The EQ embed wears the wrapper markers the
   c1 tool lacks (`data-staged-tool="equalizer"` + note). Rows use the
   SettingField row grammar (`settings-field__row`, label left / control
   right) — no new CSS files (mission scope): only shared-sheet classes.
2. **Player ToolsDialog** (`dialogs/ToolsDialog.tsx`) — ToolsDialogShell
   chrome + the Tabs primitive: **Audio tab** = Equalizer (staged wrapper) +
   Compressor + Spatializer + Stereo Widener + Visualizer; **Video tab** =
   Colors + Crop + Essential + HDR. Cards ship collapsed (frames); tab
   semantics = the primitive's (roving tabindex, arrows/Home/End). dialogs.css
   adds the tab-column layout + `:has(.eq-tool--open)` reveal for the EQ
   staged note (sibling-card parity).
3. **The trigger seam** — `TOOLS_DIALOG_EVENT = "lumen:open-tools"` (the
   `lumen:open-media` CustomEvent pattern) + `openToolsDialog(tab)` helper +
   `ToolsDialogHost` (listener; mounts per-open, keyed by requested tab so a
   video request while open remounts on Video). All exported from
   dialogs/index.ts.
4. **i18n** — `w26.c5.ts` (12 keys: section title, 5 row labels, EQ staged
   note, dialog title + tab labels, trigger aria); "Equalizer"/"Equalizer
   preset" REUSED from w26.c1's keys via the useEffectsMsg seam (no
   re-declaration).

## Decisions (frames + frozen APIs win)

- **Retired from Effects**: volume/mute live controls + balance pending row
  (frame has none; live control stays in the ControlBar; the schema Volume
  section of `Settings - audio.svg` owns settings volume when seeded) and
  the video-adjust sliders (ColorsTool carries that staging in the dialog;
  `Settings - video-1.svg`'s Picture section is the video area owner's
  mount). Handoffs logged, not silently dropped.
- **No duplicate preset row**: the frame places "Equalizer preset" outside
  the EQ panel; the frozen c1 API carries it inside — one live preset
  control instead of a staged dead twin beside it.
- **Static dialog title "Tools"**: the Tabs primitive is uncontrolled (no
  change seam) — per-tab titles would need primitive changes (additive ask,
  not mine).
- EQ embed mounts `defaultOpen` (frame audio-1 = expanded state; audio.svg =
  collapsed section).
