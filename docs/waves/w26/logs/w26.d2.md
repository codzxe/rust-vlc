## Method

sets `document.documentElement.dataset.theme="light"` **after** load (the
app's theme sync re-pins `data-theme` on mount, so an init-script-only
set is silently reverted — probes must re-apply post-`networkidle`).
Player-family routes need the `?onboarding=1` screenshot bypass (App.tsx
header) or the first-run gate redirects everything to /onboarding.
Element-level clip probe: `/home/z/w26d2-clip.mjs` (flags any visible
element outside the viewport whose ancestors don't scroll).

Outputs: `/tmp/shots-w26d2-light/` (1440×900, 14 routes + player-loaded
attempt), `/tmp/shots-w26d2-1024/` (1024×768 dark, 14 routes). Zero
console errors on every route, both sweeps.

## Real breaks found + fixed (2)

1. **Play-pill glyph near-invisible (both themes, worst in light).**
   `.lumen-icon-button:disabled` (button.css, (0,2,0), later import
   order) clobbered `.lumen-controls__play`'s
   `--color-stroke-icon: var(--color-content-on-accent)`: the disabled
   empty-state play glyph rendered tertiary-gray on the accent pill —
   #9a9a9a on #d37918 = **1.8:1** in light (vision-flagged near-invisible
   on /player light). Fixed in
   `ui/src/screens/player/controls/controls.css`: re-pin the ink at
   (0,4,0) rest / (0,5,0) disabled → glyph is on-accent near-black in
   both themes and any import order. (Out-of-lane — controls lane owner
   + Lead flagged.)
2. **Ghost icon buttons under 3:1 in light (app-wide).** The light icon
   token (W25 §1 `--color-stroke-icon: #9a9a9a`) puts every
   `.lumen-icon-button` rest glyph at 2.1–2.3:1 on #f0f0f0/#efefef chrome
   and 2.0:1 on the #dedede hover chip — under WCAG 1.4.11 (interactive
   iconography ≥3:1); vision flagged the /player/music playlist-header
   cluster as near-invisible (BROKEN verdict). Fixed in
   `ui/src/components/button/button.css`: light-only remap to
   `var(--color-content-secondary)` (4.1–4.7:1), custom property only so
   pressed-accent rules (e.g. playlist view toggles) keep winning;
   companion (0,4,0) rule preserves the disabled tertiary story. Dark
   untouched; the token itself (decorative `.lumen-icon` consumers)
   untouched. (Out-of-lane — button lane owner + Lead flagged.)

Post-fix re-shoot + re-audit: player, player-music, miniplayer → all
CLEAN (music header cluster now "dark gray glyphs on light panel …
readable"). Post-fix probe (computed styles): enabled ghosts #6e6e6e,
pressed accent #c2711a, disabled tertiary #9a9a9a, pill glyph
rgb(9,9,9) on #d37918 — in both themes.
