## Findings

### [g19-P1-1] P1 · Sorting menu · 778px popup has no viewport clamping — clipped at both mandated sizes
- **Screen/reproduce:** `/playlist` → open a playlist → click the sort trigger. Measured popup
  y138, h778 → **bottom 916** vs viewport **900** (1440×900: last row band cut 11px) and **768**
  (1024×768: rows 14–16 below the fold — "URI Ascending/Descending", "Disc Number
  Ascending/Descending" unreachable by mouse, text clipped). CONTRACT §7: "no clipped text at
  1440×900 or 1024×768". The shared `MenuPopup` got viewport flip/shift in w26.f07;
  `PlaylistOptionsMenu` is a bespoke popup with **no measuring at all** (absolute `top:100%`).
- **Files:** `ui/src/screens/playlist/options/PlaylistOptionsMenu.tsx` (add measure/flip/shift or
  reuse MenuPopup), `options.css` (`.lumen-plo__menu--above` exists but nothing selects it).
- **Frame evidence:** frame itself is a bare 265×776 panel; the clip is app-side. Measurements:
  `measure-real.json` → `"bottom":916` at both sizes.
- **Fix direction:** on open, measure trigger + popup; if it would overflow, open **above**
  (placement prop already exists) or cap height with internal scroll; keep 265px width.

### [g19-P1-2] P1 · Add-subtitles dialog · one Escape on an open dropdown closes the entire dialog
- **Screen/reproduce:** `/playlist` → open playlist → "Add subtitles" → open the "Filename
  matching" dropdown (or either pill) → press **Escape** → the list AND the dialog both close
  (verified: `debug3.mjs` → `after ONE escape: {dialog:false, list:false}`). Expected: first
  Escape dismisses the list and restores focus to the trigger; the dialog survives.
- **Files:** `ui/src/components/menu/Dropdown.tsx` (Escape/Tab handler calls `preventDefault()`
  but **not `stopPropagation()`** → bubbles to the Dialog focus-trap's `onClose`), interacting
  with `ui/src/components/menu/Dropdown.tsx:170` + `components/surface/Surface.tsx` (Dialog trap).
  Menu-lane file — routing needed (see Notes).
- **Frame evidence:** interaction-model expectation (APG combobox + modal dialog); no frame.
- **Fix direction:** `event.stopPropagation()` in the Dropdown keydown when the list is open
  (Escape/Tab/arrows); regression-test "Escape with list open keeps dialog open".
