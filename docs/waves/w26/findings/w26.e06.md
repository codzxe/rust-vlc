## Findings

### F1 — P1 · enum rows render as stacked radio blocks, not dropdowns
- **Surface**: privacy (`privacy.crash-reports`), playback (`playback.subtitle-mode`);
  would hit every enum row in settings.
- **Evidence**: live DOM control = `.lumen-radiogroup` with option rows "Off/Ask/Send"
  (h=120px) and "Automatic/Forced only/On/Off" (h=160px) — always-expanded Values-1.svg
  grammar. Frame grammar (§D2 row inventory, video SVG carries literal `Dropdown`
  elements): closed trigger 320×36 rx6 `#090909` + inner 316×32 rx4 `#191919`, value
  `#8F8F8F` ≈15px, chevron-down 10×5 @ 33px inset. b01 log (line 135/202) also expected
  "dropdown 320×36 r6" for row internals.
- **Location**: `ui/src/screens/settings/SettingField.tsx:73-84` (enum → RadioGroup).
  A compact-density Dropdown built for exactly this grammar exists UNUSED:
  `ui/src/components/menu/Dropdown.tsx:54` ("compact ≈ Setting Preset.svg settings dropdowns").
- **Suggested fix**: map enum → `Dropdown` (density compact) in SettingField; keep
  RadioGroup only for frame radio-row cases (e.g. audio-1 startup volume, §D2 "Radio rows").
- **Confidence**: high.

### F2 — P1 · text/number/list rows have NO visible label
- **Surface**: playback (`preferred-audio-languages`, `preferred-subtitle-languages`,
  `default-rate`), video/codecs (`cache-demux-mib`, `network-mib`).
- **Evidence**: DOM `leadRect` height 0 / `visibleLeadLabel: null` for those rows; inputs
  render as floating "en"/"1"/"32"/"64" boxes with no left label (vision: "orphaned 'en'
  inputs with no labels"). Frame: every row is label-left (labels `#8F8F8F` ≈15px @ x240).
  Cause: `SettingField.tsx:141` renders the lead label only for `bool`/`enum`/Special, and
  `settings.css:432-441` (`.settings-field__bare .lumen-field__label`) clips the form
  field's own label to 1px — the comment claims "the row renders it", but the row does not.
- **Suggested fix**: drop the type gate at `SettingField.tsx:141` so every row renders the
  lead label span (keep the inner label clipped for a11y association).
- **Confidence**: high.
