## Findings

### F1 — /settings/global content: Appearance / Startup / Diagnostics absent — P1

- Surface: `/settings/global` content column.
- Evidence: DOM inventory (probe) renders only sections `language` (1 row),
  `updates` (1 row), `about`. Figma §C1 wants **Appearance** (Theme
  segmented · Accent color 9 swatches · Interface language dropdown),
  **Startup** (2 toggles), **Diagnostics** (Developer mode · Save a log ·
  Log file + Browse · Log details), + the Advanced Options bar. Vision
  verdict GAPS: "Appearance / Startup / Diagnostics — all missing in
  Image 1". Root cause: the b02 seed left global's schema entries untouched
  (w26.b02 log: "All existing entries (global/interface…) untouched") —
  the D3 "NEEDS-MERGE" work has not landed.
- Location: `ui/src/screens/settings/generated/Screens.tsx:56–67`
  (GlobalScreen = 1 language section); `ui/src/screens/settings/areas/index.tsx:83–90`
  (global = generated language + AboutArea only); seed source
  `schemas/settings.toml` (no appearance/startup/diagnostics keys).
- Suggested fix: seed the C1 rows (theme/accent/startup-dialogs/
  update-checks/diagnostics) and compose the Appearance section (Theme →
  SegmentedControl, Accent color → SwatchGroup, Interface language →
  Dropdown). Keep the About fold below per the Lead's about→global merge.
- Confidence: high.
