## Findings

### F1 — P3 · Miniplayer/playlist "N items" summary renders "1 items" (no pluralization)
- **State + reproduce:** `/miniplayer` → queue toggle → "+" → pick any source. Queue summary reads **"1 items"** (probe: `summary: "1 items"`). Same grammar in the docked playlist panel header (`PlaylistPanel.tsx:177`) and the mini queue meta row.
- **Responsible files:** `ui/src/screens/player/variants/MiniPlayer.tsx:493-496` (`` `${playlist.entries.length} ${m("playlist.panel.count-suffix")}` ``) reusing `playlist.panel.count-suffix` = `"items"` (`ui/src/i18n/messages.ts:1541`); `ui/src/screens/playlist/PlaylistPanel.tsx:177` (same pattern). The UI's `useMsg` has no plural machinery (the Rust `localization` crate does; the UI catalog doesn't).
- **Frame evidence:** `Miniplayer.svg` summary is "N items" — the frame only ever shows a plural count; nothing frames N=1.
- **Fix direction:** either a plural-aware count key pair (`…count-one`/`…count-other`, resolved at the call site) or copy that stays correct at N=1 ("Queue · 1 item"). Cosmetic; not blocking.

### F2 — P3 · Music-variant dock width 300px vs the 283px frame scale used everywhere else
- **State + reproduce:** `/player` dock = **283px** (`player.css:101`, `377px@1920 × 0.75`, h03 frame pin); `/player/music` dock = **300px** (measured live, both routes probed back-to-back).
- **Responsible files:** `ui/src/screens/player/variants/variants.css:654-655` — `width: 300px; /* structural: frame column 377px @1920 ≈ 19.6% of width ≈ 300px at app scale */`. The rationale is fuzzy: the same 377px `Player - Music-1.svg` column at the 0.75 app scale is 283px (19.6% of 1440 = 282.5, not 300), so the two variants' docks disagree by 17px for the same frame column.
- **Frame evidence:** `Player - Music-1.svg` playlist column 377×986 — identical width to `Player.svg`'s sidebar that the full player pins at 283.
- **Notes:** deliberate + documented in code (i04 verified art cx=720 with the 300px dock), which is why this is a P3 observation for the Lead rather than a defect; unifying at 283 (or re-justifying 300 with a real frame measure) is a one-line change in the music lane's file.
