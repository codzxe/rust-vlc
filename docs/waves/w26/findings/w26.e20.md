### F2 — lane-msg widening hook re-implemented in 20 files, with drift — **P2**
**Evidence**: `const laneCatalog = {...laneKeys}; use<X>Msg() { m(key) ?? laneCatalog[key] }`
in **20 files** (grep `laneCatalog\[key\]`). Variants diverge: usePlaylistMsg wraps in
useCallback, most others don't; useVisualizerMsg adds a `?? key` raw-key fallback the others
lack (subtle behavior difference: renders the key string instead of undefined);
PlayerScreen.tsx:116 + PlaylistPanel.tsx:50 additionally duplicate the same `c6Catalog`
constant from the same c6Keys import.
**Location**: 20 files (list in method); e.g. src/screens/playlist/usePlaylistMsg.ts:18–30,
src/screens/player/tools/visualizer/useVisualizerMsg.ts:16–33,
src/screens/player/PlayerScreen.tsx:116, src/screens/playlist/PlaylistPanel.tsx:50.
**Fix**: one utility `createLaneMsgHook(catalog)` in i18n/ (owns the fallback + callback
policy); lanes keep only their key files. ~300 lines collapse.
**Confidence**: high.

### F6 — component API convention inconsistencies (frozen; record for next major) — **P3**
**Evidence** (all read from source):
- Accessible-name prop: `label` (IconButton, Dropdown, Dialog/Sheet, RadioGroup family) vs
  `ariaLabel` (ContextMenu.tsx:37 — also non-idiomatic vs React `aria-label`) vs `content`
  (Tooltip). Same concept, three names.
- className merge pattern: `[...].filter(Boolean).join(" ")` (Button/IconButton/Toggle/
  Card/HeroPill/EQSlider/all form controls) vs `` `lumen-x ${className}`.trim() `` (Dialog,
  Sheet, Panel, Well, Separator, SectionHeader in Surface.tsx). Both correct; two idioms.
- ref convention: forwardRef (button/slider/form fields) vs React-19 ref-as-prop
  (Dropdown.tsx:43, ContextMenu.tsx:44) — mixed migration state.
- Treatment prop name: `tone` (Panel/Dialog/Sheet) vs `variant` (Card/Button).
- Callback naming otherwise consistent (onXxx everywhere: onChange / onChangeLive+onCommit
  slider family / onClose overlays / onSelect menus). Prop ordering consistent
  (label/value/options → disabled/invalid → id/className last).
**Location**: src/components/menu/ContextMenu.tsx:37; src/components/surface/Surface.tsx:164,
211, 256, 303, 324, 354; src/components/menu/Dropdown.tsx:43.
**Fix**: no mid-wave action (rule 3 freezes signatures). Register in wave-j debt list;
new components should adopt `label` + array-join + one ref convention.
**Confidence**: high.
