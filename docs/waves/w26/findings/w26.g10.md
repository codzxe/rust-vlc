## Findings

### [g10-P1-1] Interface screen content does not match the reference frame (13/16 rows absent)
- **Screen/reproduce**: `/settings/interface` @1440×900 (default state; `interface-1` is the same frame).
- **Frame evidence** (`Settings - interface.svg` semantic ids, §C2): sections **Skin** (Use a custom skin ON · Skin file + Browse), **Window** (Play video inside main window · Resize window to fit video → "Never" · Remember window size and position · Keep window above other windows · Show window decorations · Show the file name in the title bar · Open fullscreen on → "Current screen"), **Playback Controls** (Start in compact mode · Auto-hide the controls → "In fullscreen only" · **Hide after** slider w/ ticks + "0 s/5 s/10s" scale · Show controls in fullscreen), **Notifications and System Tray** (header at y837).
- **Current** (DOM dump): sections Appearance (Theme segmented) + Window (Start maximized · Remember window geometry · Window width · Window height · Minimum window width · Minimum window height) — none of the frame's Window rows, no Skin, no Playback Controls (the Hide-after slider grammar never appears), no Notifications header.
- **Responsible**: `schemas/settings.toml` (interface seed — settings-seed lane f01), `ui/src/screens/settings/generated/schema.ts` (generated), `ui/src/screens/settings/areas/interface.tsx` (renders schema only, by design), `ui/src/screens/settings/areas/index.tsx`.
- **Fix direction**: seed the 14 interface rows (skin-file as `path` w/ Browse companion, resize/open-fullscreen/auto-hide as enums with frame values, hide-after as `duration-ms` slider) + a Notifications section header; drop or re-home the window-metric rows (frame shows none; min-* are advanced anyway).

### [g10-P1-2] Global frame's Appearance section is split/misplaced — Theme row renders on the wrong screen
- **Screen/reproduce**: `/settings/global` — frame section 1 "Appearance" holds **Theme · Accent color · Interface language** (3 rows, §C1).
- **Current**: a leading standalone "Language" section (row label "Language"), Appearance = accent only; the Theme segmented control renders on `/settings/interface`, which the interface frame does not show at all. Both screens therefore deviate structurally from their frames.
- **Responsible**: `schemas/settings.toml` (`interface.theme` placement), `areas/index.tsx` (THEME_SETTING_KEYS follows the seed), `generated/Screens.tsx`.
- **Fix direction**: move the theme key/row to the global screen's appearance section (analysis D3 "NEEDS-MERGE" already names this); fold `global.language` into Appearance as its 3rd row and drop the standalone Language section.
