## Top-5 defects by shamefulness

1. **Music transport tail eats the seek well's frame proportion** (both music states).
   Live well 782px = 54.3% of window, center 44.7%; frame 1246/1920 = 65%, center
   49.6%. Cause: seven right-side clusters (mute/slider/audio/subtitles/settings/
   queue/app-menu, x=1095..1424) where the frame's music Controls carries ~volume.
   Files: `ui/src/screens/player/controls/ControlBar.tsx` (no per-variant cluster
   reduction) + `ui/src/screens/player/variants/variants.css`. Repro: `/player/music`,
   probe `[data-control]` inventory (my band.js).
2. **Miniplayer card vertical rhythm compressed** — seek→title gap 6px vs frame
   26.5px; card 312 vs 339. The most visible craft miss in the family.
   File: `variants.css` `.lumen-mini__title`/`.lumen-mini__meta` margins. Repro:
   `/miniplayer` rect probe (title y=557 after seek bottom 551).
3. **Miniplayer overlay omits prev/next; corners deviate from playing artboards**
   (frame: centered prev/play/next row at video mid + close TL/expand TR; live: one
   close|play|expand row). File: `MiniPlayer.tsx` `.lumen-mini__transport`. Repro:
   `/miniplayer`, probe transport rect vs Miniplayer.svg artboard y=1238 glyph paths.
4. **44px queue rows are dead CSS — no enqueue path exists in the product.** The
   gfix-F pin (variants.css:323) cannot render anywhere; every queue surface shows the
   honest empty state ("0 items"). Cross-lane seam g20-P2-3 (PlaylistProvider enqueue
   has zero UI callers) — needs a Lead/demo decision; as shipped, the miniplayer's
   most distinctive frame feature (drag-handle rows with durations) is unverifiable.
5. **/miniplayer route keeps the full shell + open 208px playlists sidebar** — the
   f08 route-aware default covers `/player*` only, so the "compact floating card"
   frame renders inside a maximized app frame, card centered in the content column
   (cx≈850) not the window (720). File: `ui/src/components/appshell/AppShell.tsx`
   `loadSidebarOpen()`. Repro: `/miniplayer` @1440 (rail 52 + sidebar 208 display:flex).

Runner-ups: video rx12 vs frame rx5 (Lead ruling pending, g07-P2-4); #191919 standing
in for frame #1B1B1B (token ask, g07-P3-5); mini seek 373 vs frame 375; video stroke
1px #404040 vs frame 2px #090909; banner #161616 vs frame topbar #1B1B1B (cross-lane).

## Would I ship

Hide-UI: yes — the zero-chrome state is paint-verified and the lock/reveal state
machine is the best-behaved thing in this family. Music mode: ship as a beta — the
geometry core (one column, window-centered art, frosted band) finally matches, but the
transport row needs one honest pass to shed the full-player tail it inherited.
Miniplayer: hold — one afternoon of vertical-rhythm work (26.5px gap, 339 card) plus a
real decision on the overlay anatomy would take it from "compact but stapled" to the
frame. The product-wide empty-queue seam (defect 4) is the deepest hole and needs a
Lead ruling, not another CSS pin.
