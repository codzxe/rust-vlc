under-counted: the border is also wrong). The frame's primary is labeled **"Save"** (SVG
group id, `opacity="0.5"`, #371f06 + #d37918) — live ships "Open stream" at full opacity,
107px wide vs the frame's 100px; functionally more honest, frame-wise a deviation, and
g20's "MATCH" verdict for this dialog ignored it. Worst states sin: the focus trap lands
initial focus on the **✕ close button** and `:focus-visible` paints a 2px orange ring at
rest (verified: `activeElement` = close, `matches(':focus-visible')` = true, 62 orange
pixels in the resting screenshot) — so every fresh opening shows an orange-ringed close
glyph and Enter dismisses the dialog instead of submitting the form. The window chrome
also invents a #404040 border and skips the frame's 95% fill-opacity + backdrop blur that
the shortcuts window faithfully keeps. Flow is the strong axis: reachable from the app
menu (Ctrl+N) and canvas menu, Escape/scrim/✕/Cancel all exit to /player, a real
`session.open` fires, and the recents list (no-frame addition, honestly documented)
persists to localStorage. g20 called this MATCH; with the divider geometry, four color
misses, the Save/Open divergence and the focus-ring-at-rest, that grade was charity.

overlay-yields-first guard, pencils deep-linking to /settings/hotkeys.

## Top-5 defects by shamefulness

1. **Netstream divider is geometrically broken AND the wrong color** — live #404040 rule
   runs flush-left (x197, panel edge) and stops 40px short on the right (x1203 of 1243);
   frame is a #222222 stroke at 20px insets both sides. Root cause:
   `ui/src/components/surface/surface.css:288` (`width:100%` on `.lumen-separator`)
   defeats the `-20px` bleed margins in
   `ui/src/screens/network-stream/network-stream.css:162–165`. Repro: /open-network-stream,
   hairline at y≈556 in a 1440×900 shot. g20 logged the color (P3-3) but called the
   placement "full-bleed divider … MATCH" — it is neither full-bleed nor frame-placed.
2. **Shortcuts window has dialog chrome but zero dialog semantics** — no `role="dialog"`,
   no focus trap; Tab walks all 146 pencil links before reaching Cancel (measured tab
   sequence). The frame depicts a modal window over the app. Files:
   `ui/src/screens/shortcuts/ShortcutsScreen.tsx` (route page, not overlay),
   `ui/src/App.tsx:126`. Repro: /keyboard-shortcuts, press Tab from search and count.
3. **Light mode erases every recessed well** — shortcuts keycaps #c2c2c2 on the #c6c6c6
   window (Δ4/255 vs dark's Δ16/255): 292 keycaps nearly invisible (pixel-verified in
   `shortcutsL.png`); netstream header #c2c2c2 on #c6c6c6 dialog, same collapse. Root
   cause is token-level (light `--color-surface` #c2c2c2 vs `--color-surface-panel`
   #c6c6c6 vs `--color-surface-deep` #bababa), surfacing in
   `ui/src/screens/shortcuts/shortcuts.css:334` and
   `ui/src/screens/network-stream/network-stream.css:47`. Repro: either dialog in light
   theme.
4. **Initial focus lands on ✕ with a painted orange ring** — the surface trap focuses
   the first focusable, which is the close button; `:focus-visible` matches (verified),
   so the resting dialog shows an orange-ringed ✕ and Enter dismisses instead of
   submitting. File: `ui/src/components/surface/Surface.tsx:79` (first-focusable
   policy) + `NetworkStreamScreen.tsx` header order. Repro: fresh /open-network-stream.
5. **Color-token debt still shipping on these surfaces** — netstream helpers and
   shortcuts column headers #828282 vs frame **#6b6b6b** (g20-P2-1, open; SVG fills
   confirm); netstream placeholder #828282 vs frame **#404040** while
   `network-stream.css` comments claim "#404040-class"; Cancel #222222 **+ 1px #404040
   border** vs frame flat **#1b1b1b**; shortcuts rules ≈#2e2e2e vs **#222222**; frame
   primary "Save" @50% vs live "Open stream" @100%/107px. Files:
   `themes/tokens.json` (token lane), `network-stream.css`, `shortcuts.css`,
   `ui/src/components/button/button.css`. g20's MATCH for this dialog over-credited all
   of these.

## Would I ship

Not as "Figma-faithful," no. The shortcuts window is one token retune, one dropdown-grammar
fix and one focus-trap away from genuinely good; the netstream dialog is carrying a broken
divider, four wrong colors, a wrong Cancel and a focus choice no reviewer should have
waved through. The frameless screens are honest and grammatical but two of them (discovery,
media-info) have no reachable body on the demo engine — I'm grading CSS promises, not
product. The 404 ships today. Family mean 7.4: a coherent, calm, near-black system with
real state discipline, held back by small stubborn geometry bugs, unresolved token debt,
light-mode wells, and semantics that lag the skin. Fix the top five and this family is an
8.5 without touching a single layout.
