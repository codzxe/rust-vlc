## Top-5 defects by shamefulness

1. **Scroll-required preset rows are un-clickable by mouse** (NEW, functional). Repro: `/player` → tools (any entry) → Audio → "Open Equalizer" → preset trigger → click row 8 "Full treble". Nothing applies; the list stays open. Root cause: `ui/src/components/menu/Dropdown.tsx` (~line 269) — unstable inline `ref` callback re-runs on every render and resets `list.scrollTop = 0`; focus-on-mousedown re-render (row `onFocus` → `setActiveIndex`) fires it mid-click, so the row escapes the cursor between mousedown and mouseup and the click lands on the list. Fix: stable ref + set scrollTop only in the open effect/useLayoutEffect. Event-log proof in `/tmp/cap-w26h13/` (diag3: `click@718,548 -> lumen-dropdown__list`).
2. **Preset trigger label ink #FFFFFF vs frame #8F8F8F ≈15px** (NEW). Repro: EQ expanded → look at the trigger ("None"). `EQ presets.svg` path `Option` fill #8F8F8F. Fix: one scope line in `equalizer.css` (`.eq-tool__presets .lumen-dropdown__value { color: var(--color-content-secondary); }`) — the file already scopes its font-size but not its color.
3. **Band label ink #828282 vs frame #6B6B6B, all 11 labels** (g15-P2-1, open ≥2 waves). Repro: EQ expanded. `--color-content-tertiary` pinned #828282 (`ui/src/tokens/generated/tokens.css` ← `themes/tokens.json`); `equalizer.css` even carries a comment claiming "frame: #6B6B6B". Needs the token lane (repin tertiary or add a quiet-ink token).
4. **Selected preset row ink #EAEAEA vs frame #8F8F8F** (g15-P3-1, still open). Repro: preset list open, row 1. Shared `menu.css` `[aria-selected="true"]` bright ink contradicts `EQ presets.svg` (all row text #8F8F8F; selection = #1F1F1F bg + #D37918 check). Fix: EQ scope override in `equalizer.css`.
5. **Preset rows lack the frame's leading EQ-curve glyphs + list 320px vs frame 348px** (g15-P3-2 + new measurement). Repro: preset list open — 8 text-only rows (`hasIcon` false ×8) where the frame draws a 22px #8F8F8F line + 1–3 #D37918 arcs per non-selected row (x39–62); and `DROPDOWN_LIST_MAX_HEIGHT = 320` shows ~6.9 rows vs the frame's 348px list (~7.4, row 8 clipped). Fix: per-preset `icon` through the existing `Dropdown` icon slot + raise the cap to 348.

Family-level note (not scored): the standalone **A8 floating audio-value readout** (`audio value.svg`: 121×37 rx6 #0E0E0E@95% + blur, #969696/#6B6B6B two-tone) remains unimplemented app-wide — assigned by the Lead out of w26.c1's scope; no lane has shipped it.

## Would I ship it?

The EQ panel itself — yes, tomorrow: the vertical-fader anatomy is the most frame-exact work I have measured in this program (0 dB fill 158, thumb at −4, tick z-order, chip rhythm — all pixel-true in both themes, keyboard-complete, zero console errors, rail pan fixed and verified at both viewports). The presets panel — no. Not with a white trigger label on a quiet panel, a selected row that ignores the frame's ink, missing row glyphs, and above all a preset picker whose last row cannot be clicked by the people it is for. Items 1, 2, 4, 5 are one afternoon of work in two files; item 3 needs the token lane. Until then: panel ships, presets get a fix-first ticket.
