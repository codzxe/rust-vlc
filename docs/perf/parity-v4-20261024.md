## 8. Reproduce

```bash
# ffprobe side (committed): -count_frames / -count_packets runs over the 21 ok files
# fresh duration + inventory:
ffprobe -v error -show_entries stream=index,codec_name,codec_type -of csv=p=0 FILE
ffprobe -v error -show_entries format=duration -of csv=p=0 FILE
# Lumen duration:
printf '{"requestId":1,"cmd":"session.open","args":{"source":{"kind":"file","path":"FILE"}}}\n{"requestId":2,"cmd":"media.get-duration"}\n{"requestId":3,"cmd":"session.close"}\n' \
  | lumen --control-stdio --json
# ffmpeg PCM MD5:
ffmpeg -hide_banner -loglevel error -i FILE -map 0:a:0 -c:a copy -f md5 -
# Lumen PCM MD5 (batch): tools/bench-vs-vlc run.py digest infra
#   (LUMEN_DIFF_FIXTURES tsv + cargo test --test lumen_pcm -- --ignored)
```
