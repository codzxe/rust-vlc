## 0. Scope and principles

1. **Everything untrusted** (MP §12): corpus files are attack inputs first, conformance
   inputs second. Malformed class B is a *security* corpus, shared with doc 11 §9.1.
2. **Generated by default** (doc 10 §5.3): if we can write it deterministically, we do;
   curated acquisition is the exception and always carries a ledger row.
3. **Clean-room absolute** (doc 11 §8.1.3, doc 10 §5.1): no fixture extracted from
   VLC or any player distribution; no fixture of unknown provenance, ever.
4. **Reproducible or it didn't happen**: every generated file traces to
   (generator, seed, params) → sha256; CI re-generates and diffs hashes (doc 10
   §5.3). Probe-work proved the pattern (gen_py.py → byte-stable fixtures) but
   also exposed the failure mode: the ffmpeg command lines behind the probe
   media were not preserved (0.B4-R V1) — this plan makes generator+seed
   commitment non-optional.
5. **Expectations are frozen evidence** (doc 10 §5.4): changing one is regression
   paperwork (doc 10 §8.2); CI recomputes hashes from artifacts, never trusts
   stored values (security-phase0 TB14).

## 1. Corpus taxonomy

Five classes. Every fixture belongs to exactly one class; every class has a
directory, a generator (or acquisition rule), and an expectation flavor.

- **A — generated-valid.** Per-family minimal-but-valid files with deterministic
  content. Direct extension of the probe-work approach (gen_py.py's
  struct-writers: WAV/RIFF, M3U/PLS/XSPF/ASX/B4S/CUE, SRT/SSA/ASS/VTT/MicroDVD/
  SubViewer/SAMI/TTML all proven in ~150 lines of Python). Phase-0/1 bootstrap:
  extend the Python generator (committed under `tests/fixtures/scripts/`);
  Phase 2: port to Rust `xtask fixtures` per card 2.A3 (AC: byte-stable across
  runs, hash-checked). Determinism: fixed seeds, no timestamps, no randomness
  except seeded PRNG (seed = fixture name). Each file hash-recorded in
  `generated/MANIFEST.toml`. Media content rule (doc 10 §5.3): sine PCM at
  chosen rate/depth; MJPEG frames from procedurally drawn colorbars/counters
  with the **frame index encoded in frame content** so seek accuracy is
  assertable.
- **B — generated-malformed** (the security corpus; feeds `sec_malformed_media`
  doc 11 §9.1 and every `fuzz_demux_*` seed set, doc 04 §8.5). Derivative
  generators, each taking a class-A parent + a recorded structure map:
  - **B1 truncate**: cut at every recorded structure boundary (after magic,
    mid-header, first chunk/atom start, mid-atom, last byte −1). Offsets derived
    from the parent's structure map — deterministic.
  - **B2 bit-flip**: seeded PRNG (seed = `sha256(parent)[:8]`, xorshift64*)
    flips exactly k ∈ {1, 4, 16} bits within the first N header bytes
    (N = per-family header extent table, e.g. 512 for MKV EBML head+segment
    info, 64 for RIFF). Reproducible byte-for-byte.
  - **B3 oversize-field**: patch family-specific size/count fields to absurd
    values (2³¹−1, 2⁶⁰): WAV `dwFileLength`, RF64 > 4 GB lie, MP4 `trun
    sample_count`, MKV unknown-size element, Ogg granule lies, ID3 size,
    TS section_length=0xFFF (doc 11 §9.1 `sec_oversized_claims` vectors).
  - **B4 nested-depth**: playlist-in-playlist recursion (depth 0/1/5/100),
    composite probing (zip containing playlist containing zip), archive
    nesting (SEC-02 probe-depth bound).
  - **B5 invalid-magic / wrong-container**: file claiming family X's magic
    with family Y's body (probe-race tests — formats.md recorded the oracle's
    own races).
  Naming: `<parent>__<op><n>.<ext>`; expectation for ALL class-B files:
  **typed error or bounded recovery; never panic, never hang, RSS within cap**
  (doc 11 §9.1 pass criterion). Class B is generated at build time or committed
  hashed — committed `[PROPOSAL]` so fuzz seeds are stable in CI.
- **C — structural features**: multi-track (2 audio + 2 subtitle + forced-flag),
  chapters (MKV chapter atoms, MP4 chap atom), cover art (FLAC PICTURE block,
  MP3 ID3v2 APIC, MKV attachment), discontinuous timestamps (PTS jumps,
  PTS < DTS, negative deltas, u32 rollover near edges — doc 10 §5.3), 0.1 s
  edge clip, ≥ 30 min long item (generated, not downloaded). These exercise
  doc 03 §4.12 timed events, track-switch scenarios, doc 01 §3.2 error variants.
- **D — curated third-party** (the *only* acquired class; ≡ doc 10 §5.1's
  `acquired/`, renamed here for class clarity — see §7 ledger). ONLY
  public-domain / CC0 / CC-BY / project-licensed test files, one ledger row
  each (source URL, license, hash, why-needed). Reserved for what generation
  cannot produce honestly: real-encoder bitstreams (H.264/HEVC/AV1 conformance
  shapes), bitmap subtitle streams (PGS/DVB), P2/P3 codec families where we
  have no encoder. Candidate sources already named by prior Phase-0 work:
  DASH-IF test vectors, Apple HLS example streams, MPEG/ISO conformance
  material (all per-file license `[VERIFY]` — subsystems §1.2). No VLC-derived
  fixture ever (clean-room); no unknown provenance.
- **E — perf corpus**: NOT detailed here — pointer to doc 12 §3.4 (format ×
  bitrate × resolution × duration tiers, ≤ 2 GiB CI budget, `--quick` ≤ 200 MiB
  subset, synthetic-by-default). E items are generated (same generators,
  different parameters) and live under `tests/fixtures/bench/`, excluded from
  the §6 v1 size budget (bench corpus is CI-generated/gitignored per doc 12).

## 2. Generator architecture and reproducibility spec

```
tests/fixtures/scripts/            # Phase 0/1: python bootstrap (gen_py.py extended)
  gen_valid.py  gen_malformed.py  gen_structural.py  structmaps.py
tools/xtask fixtures               # Phase 2: Rust port (card 2.A3), same CLI/outputs
```

- **Determinism contract**: same toolchain + same seed ⇒ byte-identical output
  (CI asserts; card 2.A3 AC). No wall-clock, no tempnames, no float formatting
  drift (integer math only in writers).
- **Structure maps**: each class-A writer also emits `<fixture>.structure.json`
  (offsets of every top-level box/chunk/page/header) — the input that makes B1
  truncation offsets and B3 field patches principled rather than arbitrary.
- **ffmpeg policy** `[PROPOSAL]`: ffmpeg may be used (a) as a *cross-check*
  oracle for generator correctness (parse our output, compare track lists) and
  (b) as a committed-command encoder for families with no feasible pure writer
  (H.264/HEVC/AV1/MP3/AAC bitstreams) — in case (b) the exact command line +
  input script + output sha256 are committed, making the file CI-regenerable;
  the binary itself is never committed. Probe-work's gap (V1: ffmpeg commands
  lost) is the anti-pattern this closes.
- **Seeds**: every generator invocation logs `seed` into MANIFEST.toml; the
  global seed root is fixed (e.g. `lumen-corpus-v1`) so the whole corpus is a
  pure function of the scripts `[PROPOSAL]`.

## 4. Expectation-record format (TOML) and storage layout

Field legend (extends doc 10 §5.4, which remains normative for the base
fields): **TRK** tracks; **DUR** duration; **SK** seek anchors+tolerance;
**FF** first-frame 8×8-block-mean descriptor (doc 03 §8 FrameRecorder);
**AP** first-samples digest (4800 samples → pinned f32 conversion);
**SC** sample table (count + per-sample PTS/DTS/size/offset/sync — the fMP4
class contract); **CU** cue list (count, first/last times, overlap flags);
**ST** style/tag coverage counters (ASS/SSA/VTT); **EP** epoch list
(bitmap-subtitle flush boundaries); **PL** resolved playlist entries
(redacted paths/URLs — SEC-09); **EV** event log (chapters, cover-art
metadata events, discontinuities detected, redirects followed).

```toml
schema = "expectation/1"            # doc 10 §5.4 base, extended
fixture = "generated/valid/mp4_mjpeg_pcm.mov"   # relative to tests/fixtures/
class  = "A"                        # A|B|C|D  (E lives under bench/, own manifest)
generator = { script = "xtask fixtures mp4 --seed=…", params = "…", }
sha256 = "…64 hex…"                 # recomputed by CI, never trusted (TB14)
size_bytes = 12_004
license = "CC0"                     # generated = CC0; D rows cite ledger row id

[tracks]        # TRK — same shape as doc 10 §5.4
duration_us = 1_000_000             # DUR
[seek]          # SK — targets_us, tolerance_us
[first_frame]   # FF — hash_y, stamp_us
[audio_probe]   # AP — first_samples_md5
[sample_table]  # SC — per-sample rows (containers that own indexing)
[cues]          # CU — [{start_us,end_us,text_digest,style_flags}]
[events]        # EV — chapters/art/discontinuity events in order
[playlist]      # PL — resolved entries, credentials redacted
[error]         # class B only: expected error kind + recovery class + budget
expected = "typed-error"            # typed-error | bounded-recovery | rejected
rss_cap_mb = 64 ; wall_cap_ms = 5_000
```

Storage layout (reconciling doc 10 §5.1; "curated" class ≡ doc 10's
`acquired/` directory — naming to be aligned by Lead, see §8 Q3):

## 5. Licensing ledger format and allowlist rules

`tests/fixtures/CORPUS.md` — one row per **curated (class D)** file, per doc 10
§5.1: `name | sha256 | size | source URL | license (verbatim statement or
link) | classification | date acquired | why-needed | consuming matrix rows`.
Generated classes carry the lighter `MANIFEST.toml` (generator+seed+hash —
we authored them, CC0, doc 10 §5.3).

Allowlist (doc 11 §8.4, final call is doc 11's): **public-domain dedications,
CC0, CC-BY (attribution in ledger), project-licensed test files**. Excluded:
CC-BY-SA and stricter share-alike; anything with no discoverable license.
Hard rules (clean-room): **no VLC-derived fixtures ever; no fixture of unknown
provenance** — an unverifiable source is a rejected source, recorded as such
in the registry row, not silently dropped. Enforcement: G6 feature-audit
extends its file check to the corpus (fixture without ledger row = CI fail);
doc 11 §8.1.4 `tools/license-audit` cross-checks rows against non-VLC sources
and flags binaries > 64 KiB outside sanctioned dirs.

## 6. Size budget and CI strategy

- **v1 committed-corpus budget: < 50 MB total `[PROPOSAL]`** — tighter than
  doc 10 §5.5's `acquired/ ≤ 150 MB` long-run allowance: v1 (Phases 1–2 +
  P0 families) is almost entirely generated (class A/B fixtures are KB-scale:
  probe-work's largest committed fixture is 8 KB). Per-class guides:
  generated A+B+C ≤ 10 MB; curated D ≤ 35 MB; single curated file ≤ 5 MB v1
  (no long-media reference — the ≥ 30 min item is generated, not acquired).
  Escalation to doc 10's 150 MB happens at Phase 5 breadth with Lead sign-off.
- **CI strategy** `[PROPOSAL]`: per-PR fast subset = Phase-2 vertical fixtures
  (AVI/MP4/WAV, growing as phases land: srt at 3.A3 track-swap, M3U at 4.D1) +
  all class-B malformed smoke (bounded-time runs) + expectation-hash recompute
  + MANIFEST regenerate-and-diff; nightly full = whole corpus, fuzz-seed
  refresh, differential M1/M3 smoke vs oracle under OH rules (security-phase0
  §5), curated-D re-hash. Bench (class E) per doc 12 §3.8 (no CI by default).
