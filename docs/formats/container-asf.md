# Container record — ASF / WMV (Advanced Systems Format)

Status: **implemented (demux) — cards 6.ASF-a/b/c + issue #9** (the
5.K3-I self-build verdict, executed). This record tracks the landed
demuxer, its verification basis, and the honest gaps.

- Layer: L2 demux, `crates/demux/src/asf/` (mod/header/data/error/
  guid/tests/test_support/fuzz), C5 std-only, zero external
  dependencies, no `unsafe` — same posture as the MKV/PS/AVI
  self-builds.
- Oracle: ffmpeg/ffprobe 7.1.5 (the `asf` muxer output is
  byte-decoded for every field below; ffprobe is the live
  differential oracle). VLC 3.0.23 `asf` demux parity: one green
  Phase-0 probe lane (`asf_wmv2_wmav2`).
- Date of evidence: 2026-10-24 (decision), **2026-11-09 (build)**.

## Parse / Decode / Encode

1. **Header object tree (6.ASF-a)** — File Properties, Stream
   Properties (WAVEFORMATEX / short-VIDEOINFOHEADER), Codec List,
   Extended Content Description, bounded Header Extension walk, a
   top-level object map (Data Object + Simple Index located), typed
   refusals for every malformed shape, damage observability.
2. **Data Object packetization (6.ASF-b)** — the packet grammar:
   error-correction flags, packet/property flags, padding, send time,
   duration, multi-payload packets, 8-byte replicated data (object
   size + preroll-offset presentation time), per-stream fragment
   reassembly under a 32 MiB object ceiling — the **hold-and-flush
   contract**: a first fragment that fills its object is held, a
   continuation (even 0-byte at the exact end) releases it, a held
   object flushes on the stream's next fragment, and the walk-end
   drain releases the rest before `EndOfStream`; a fragment whose
   head was never seen (seek re-anchor landing mid-object, offset ≠ 0
   with no open object) is an orphan — skipped, never fatal; the
   demuxer emits one
   `Packet` per completed media object with preroll-subtracted stamps
   on the track's own base (sample ticks for audio, the verified
   millisecond clock for video). Unverified shapes (variable packet
   size, the compressed 1-byte replication form) refuse typed, never
   guess.
3. **Simple Index Object seeking (6.ASF-c)** — the index is parsed on
   first seek (interval + per-bucket packet numbers; see Timestamps
   below) and maps time → packet directly; indexless files (audio-only)
   get the bounded linear scan (`MAX_LINEAR_SEEK_PACKETS` = 4096) with
   the honest `seek.too-slow` refusal past the budget. `seekability`:
   `Fast{indexed}` with an index, `SlowLinear` without.

Encode: out of scope (VLC's `asf` *muxer* is sout-side; feasibility §6).

Unsupported constructs (honest v1 exclusions, enforced typed):
broadcast/live-mode ASF (`demux.asf.broadcast-unsupported` — ffprobe
itself refuses those files, measured), DRM/"Protected" paths (the
encryption bit field is spec-unpinned; carried raw), script streams,
variable-size packet files (`demux.asf.packet.variable-size-unsupported`).

## Evidence (what was verified, and how)

- **Field-level:** every layout in `crates/demux/src/asf/` was
  byte-verified against ffmpeg 7.1.5 muxer output — the object tree,
  the packet/payload grammar (packets close exactly: payloads +
  padding = packet size), and the Simple Index layout (file id + 1 s
  interval QWORD + one unpinned DWORD + 6-byte `(DWORD packet number,
  WORD count)` entries; the number is non-decreasing across the
  corpus — the seek fact). **[VERIFY-P0: the MSDN ASF spec text was
  not acquirable in the sandbox; spec-pin pending]** — the build is
  clean-room against muxer output + independent tests only.
- **Differential (6.ASF-d):** the §1.2 fixture family (10 files:
  WMAv1/v2, WMV1/WMV2, msmpeg4v3, mjpeg, PCM, ADPCM, A/V mixes,
  8 KB packets) is regenerated by the test suite (sha256-pinned),
  walked end-to-end, and cross-checked live: stream/codec identity
  vs `ffprobe -show_entries stream=codec_name`, and per-track
  media-object counts vs `ffprobe -count_packets` (exact equality).
  Stamps asserted against per-fixture measured first pts (ffprobe's
  own arithmetic — preroll subtracted; measured: the A/V fixtures'
  video grid starts 64 ms in, every other stream at zero) and
  monotonic per track; indexed
  fixtures seek mid-file and resume. Skips loudly when ffmpeg is
  absent.
- **crates.io (2026-10-24):** no adoptable crate (`wmvkit` 0.1.0
  recorded as oracle candidate only — single release, below the bar).

## Tracks (selection, default, languages)

Stream Properties → track table (stream number 1–127 joins payload
stream bytes; one track per audio/video SP in file order). Language
list / mutual-exclusion objects: not parsed (advisory; the §5.K3-I
split-card listed them under 6.?c's optional scope — deferred, gap
recorded here).

## Seeking

Implemented: Simple Index Object (1 s interval buckets on the
preroll-offset clock) → packet-number landing with walk re-anchor
(half-delivered fragments dropped, flush endpoint re-armed; the
re-anchored walk skips orphaned continuations until the next first
fragment re-synchronizes each stream); targets
beyond the last bucket clamp to it. No index → bounded linear scan on
packet send times; past 4096 packets → `demux.asf.seek.too-slow`
(the mkv SlowLinear precedent).

## Timestamps

Payload presentation times (replicated data) ride the preroll-offset
millisecond clock; the demuxer subtracts the FPO preroll (measured:
ffprobe's zero-based pts is exactly this arithmetic) and converts onto
each track's own base. FPO Play Duration stays advisory-only (ffmpeg
pads it — 4.164 s declared for a 1.128 s file, measured). Track spans
remain UNKNOWN (the ASF-a flagged decision: spans come from packet
stamps, not FPO durations).

## Corrupt-input behavior

Object-size/GUID bounds checks → typed `Corrupt` refusals; junk
objects skipped by size (damage-logged); truncation mid-object →
`Corrupt::Truncated`; packet grammar violations →
`demux.asf.packet.bad-flags` / `packet.bad-length` /
`payload.bad-replication`; ceilings per the §12 bomb policy
(header 1 MiB, index 1 MiB, object 32 MiB — typed `ResourceLimit`).
Zero panics in non-test code; `fuzz_demux_asf` target registered.
