## Demux / Mux / Encode

- **Demux (landed)**: RIFF chunk walk with parent/stream clamping of
  every declared extent; `hdrl`/`strl` track discovery (video/audio
  stream headers, `strf` format facts); `LIST movi` packet extraction
  walking chunk-by-chunk — index or no index; `idx1` as the seek
  table (keyframe flags + binary-searched time→position mapping)
  with the position-restoring linear-scan fallback when `idx1` is
  absent; MJPEG + PCM packet extraction (the first-vertical payload
  pair); seek-to-time. OpenDML (`AVIX`/`dmlh`) tall sizes are the
  documented OpenDML extension of the same RIFF grammar.
- **Mux / Encode: not in v1** — the matrix row is demux-scoped; no
  AVI writer exists in-tree.
