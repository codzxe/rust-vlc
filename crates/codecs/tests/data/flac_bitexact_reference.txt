# and one [corpus.<name>] section per real-corpus FLAC
#   $LUMEN_CORPUS/media/<name>.flac
# (corpus is /tmp-resident and may be re-imaged away — the corpus tests
# SKIP with a message when LUMEN_CORPUS is unset or the file is absent;
# the fixture rows are the always-on coverage).
#
# PROVENANCE (honesty rules, AGENTS.md sec.3.4): every fixture's PCM
# essence is authored by the external ffmpeg 7.1.5-0+deb13u1 encoder
# (oracle, never a dependency) with the exact commands below, 2026-10-24;
# the SEEKTABLE carrier additionally has its metadata block authored
# in-tree by data/flac_insert_seektable.py (recorded verbatim below in
# spirit — run the committed script; ffmpeg 7.1.5's flac muxer writes NO
# seektable, verified: blocks are STREAMINFO/VORBIS_COMMENT/PADDING).
# The reference MD5s are ffmpeg's own decoded dumps (commands below);
# for every file the STREAMINFO md5 field equals the native-width dump
# (s16le for 16-bit, s24le for 24-bit), independently confirming the
# FLAC MD5 convention AND our decoder's byte layout. The tests compare
# Lumen's decoded output against these digests AND the STREAMINFO md5.
#
# Generation commands (verbatim; cwd anywhere, sha256 of results below):
#   ffmpeg -y -f lavfi -i "aevalsrc=0.5*sin(2*PI*440*t)|0.5*sin(2*PI*440*t):d=0.5:s=44100" \
#     -c:a flac -sample_fmt s16 -compression_level 8 flac_s16_stereo_44100.flac
#   ffmpeg -y -f lavfi -i "sine=frequency=330:duration=0.25:sample_rate=44100" -ac 1 \
#     -c:a flac -sample_fmt s16 -compression_level 8 flac_mono_s16_44100.flac
#   ffmpeg -y -f lavfi -i "aevalsrc=0.45*sin(2*PI*293.66*t)|0.45*sin(2*PI*369.99*t):d=0.4:s=48000" \
#     -c:a flac -sample_fmt s32 -compression_level 8 flac_s24_stereo_48000.flac
#   ffmpeg -y -f lavfi -i "aevalsrc=0.5*sin(2*PI*440*t)|0.5*sin(2*PI*440*t):d=4.5:s=44100" \
#     -c:a flac -sample_fmt s16 -compression_level 8 flac_s16_stereo_44100_seektable_src.flac
#   python3 data/flac_insert_seektable.py flac_s16_stereo_44100_seektable_src.flac \
#     flac_s16_stereo_44100_seektable.flac   # drops PADDING, inserts 6-point table
#
# Reference dumps (per file; MD5 over the whole stream):
#   ffmpeg -i F.flac -f s16le -c:a pcm_s16le -  | md5sum
#   ffmpeg -i F.flac -f s24le -c:a pcm_s24le -  | md5sum
#   ffmpeg -i F.flac -f s32le -c:a pcm_s32le -  | md5sum
#   ffprobe -v error -select_streams a -show_entries packet=pts -of csv=p=0 F.flac
#     (packet pts are sample numbers; the per-frame list is recorded in
#      first_samples and pins the decoder's BlockMeta.first_sample and
#      the seek planner's resolution, tail frame included)
#
# The 24-bit comparison base is the s32le dump (ffmpeg left-justifies
# 24-bit FLAC into s32; our decoder emits S24 3-byte and the test lifts
# by << 8). The s24le dump MD5 doubles as the STREAMINFO-md5 check.
