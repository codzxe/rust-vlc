#   ffmpeg -v error -i FILE -map 0:a -f md5 -                # the card's literal command
#   ffmpeg -v error -i FILE -map 0:a -c:a pcm_f32le -f f32le - | md5sum
#   ffmpeg -v error -i FILE -map 0:a -c:a pcm_f32le -f f32le - | wc -c
#
# WHY the two digests differ: `-f md5` hashes ffmpeg's decoded frames
# in their native PLANAR float layout (fltp); `-f f32le` is the
# interleaved layout every consumer (and this decoder) emits. The
# comparable differential base is the f32le digest; the card's literal
# command is recorded alongside for traceability.
#
# The differential window (the 5.A3 mp3 gapless-window pattern):
# Vorbis is lossy — independent decoders differ in float rounding — so
# the suite asserts (1) the exact ffmpeg sample count on the aligned
# window, (2) our window's MD5 as the hard regression pin
# (`lumen_window_md5`, over f32le bytes with -0.0 canonicalized to
# +0.0 — the MDCT emits -0.0 on digital silence; ffmpeg emits +0.0),
# and (3) the live-ffmpeg per-sample max delta ≤ `max_delta` when an
# ffmpeg binary is present. `head_trim` is the ENCODER HEAD DELAY —
# for multi-page streams it equals the decoder-measured first-stamp
# shift (raw_emitted − granule at the first stamped page: 128 / 256);
# the raw−final-granule distance is delay + TAIL PADDING (the 5.A3
# gapless split — e.g. 67264 − 66150 = 1114 = delay 128 + padding
# 986), and the window's `window_samples` length cut excludes the
# tail. FINISHER CORRECTION 2026-10-26 (P5-B2F): the prior session
# had recorded the raw−granule distances (1114 / 384) as head trims
# for the two sine fixtures — mis-aligned windows whose recorded
# `max_delta = 1e-7` was never actually measured (live delta was
# ~9e-2). Corrected by exhaustive alignment scan (argmin of the
# per-sample max delta vs the pinned ffmpeg 7.1.5 output),
# cross-checked against the decoder's first-stamp shift measurement;
# both digests below are the corrected windows'. For the two
# single-data-page streams (silence, tagged) the only stamp is the
# EOS page, so the pts series stays honestly Missing and the trim is
# the scan-derived delay (832 / 128 — the tagged stream's EOS
# measurement 636 = delay 128 + padding 508). The silence lane is
# the true bit-exact corridor: digital silence decodes to exact zeros
# in every conforming decoder, and our canonicalized window MD5 equals
# ffmpeg's f32le digest byte-for-byte.
