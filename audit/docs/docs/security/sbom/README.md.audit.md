known limits, and even flags the un-run schema validation with [VERIFY]. Its
three failures are all the same failure — it describes the *regenerated*
SBOM contract, while the *committed* `cyclonedx.json` violates it by one
dependency edge, and the README's own threat statement ("the merge gate
fails") is live right now: CI's cargo-deny job ends with
`cargo run -p xtask --locked -- sbom --check`, which on this HEAD must exit 1.
The doc says what should be true; the artifact does not match the doc.
