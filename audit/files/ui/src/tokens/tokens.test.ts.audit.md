## 1. One-paragraph verdict
A real generation-drift gate. The generated tokens.css is pinned by
sha256 (both locally recomputed via `crypto.subtle.digest` and against the
generated module's own `TOKENS_CSS_SHA256` constant), the semantic-name set
is diffed exactly against the `:root` block's CSS custom properties
(129-133), and the W25 measured values are pinned one declaration at a time
(surfaces, accent family, EQ band accents, Inter stack, Solstice-remnant
absence). A stale `npm run tokens:generate` or a hand edit to
themes/tokens.json fails loudly here.
