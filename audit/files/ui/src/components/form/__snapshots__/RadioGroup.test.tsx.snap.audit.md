## 3. Findings
### F-001 [S4] Snapshot embeds React's useId format — React upgrades break the golden on noise
Where: ui/src/components/form/__snapshots__/RadioGroup.test.tsx.snap:7-8
Code:
```
  class="lumen-radiogroup"
  id="_r_9_"
  role="radiogroup"
```
(likewise `id="_r_9_-light"` etc. at 18, 36, 53 and `name="_r_9_-radio"`)
What is wrong: The golden pins React 19's internal useId token format
(`_r_9_`). Any React upgrade that changes the id scheme (as 18→19 did)
fails this snapshot on pure noise, training contributors to `-u` update
snapshots reflexively — the moment the golden stops meaning anything.
Why it matters: Snapshot-hygiene: a golden that cries wolf erodes the
protection it exists to provide.
What correct looks like: Normalize ids in the assertion (e.g. serialize
then replace /_r_\d+_/g with `_ID_`) before toMatchSnapshot.
Confidence: HIGH — Verification: read; React pinned exactly (19.3.1,
package.json) so today it is stable.
