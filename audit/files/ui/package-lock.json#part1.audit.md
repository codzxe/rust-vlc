## 3. Findings
### F-001 [S4]
Where: ui/package-lock.json:62-71 and 88-97 (the two nested lru-cache copies)
Code:
```json
    "node_modules/@asamuzakjp/css-color/node_modules/lru-cache": {
      "version": "11.5.3",
```
(and, identically)
```json
    "node_modules/@asamuzakjp/dom-selector/node_modules/lru-cache": {
      "version": "11.5.3",
```
What is wrong: The same tarball (version 11.5.3, identical integrity sha512-U4N8Fgzm…) is nested twice in the tree instead of hoisted once. Standard npm behavior when the root-level lru-cache slot resolves to a different major (the @babel/helper-compilation-targets requirement at :197 is lru-cache ^5.1.1), so the 11.x copies nest — but it is still two on-disk copies of one library where one would do (a root-level 11.5.3 + one nested 5.x would also have been valid).
Why it matters: Install-size duplication in the dev tree; cosmetic for a dev-only package, but the kind of thing `npm dedupe` exists for.
What correct looks like: A hoisted lru-cache@11.5.3 at the root with only the babel-required 5.x nested (the exact layout npm's hoisting heuristics may or may not produce — acceptable as-is, hence S4).
Confidence: HIGH — Verification: read both entries + the :197 requirement.
### F-002 [S4]
Where: ui/package-lock.json:7-9 (root entry) vs ui/package.json:1-5 and the repo LICENSE
Code:
```json
    "": {
      "name": "lumen-ui",

```
What is wrong: Neither ui/package.json nor the lock's root entry declares a license field, while the repository LICENSE is MIT ("Copyright (c) 2026 Lumen Media Player Contributors"). The UI sub-package is license-undeclared.
Why it matters: Hygiene: `private: true` blocks accidental publishing, so nothing leaks, but any consumer tooling (or a future publish) reads "UNLICENSED" for the UI half of an MIT repo. Note also that no npm-side license gate exists (cargo-deny covers only the Rust graph — baseline #25).
What correct looks like: `"license": "MIT"` in ui/package.json (and regenerate the lock's root entry).
Confidence: HIGH — Verification: read both files + LICENSE head.
