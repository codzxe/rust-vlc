## 3. Findings
F-001 [S4]
Where: crates/plugin-host-wasm/src/sha256.rs:170-174
Code:
```
    let mut out = String::with_capacity(64);
    for b in digest {
        out.push_str(&format!("{b:02x}"));
    }
```
What is wrong: 64 temporary `String` allocations per digest where a `u32`-pair hex encode (or `write!` into the pre-allocated string) would be zero-allocation. Negligible at the crate's use sites (one digest per manifest/module at install/package time), hence S4. Confidence: HIGH — Verification: read.
F-002 [S4]
Where: crates/plugin-host-wasm/src/sha256.rs:52,81
Code:
```
        self.total_len = self.total_len.wrapping_add(data.len() as u64);
```
What is wrong: Length accounting wraps silently past 2^64 bytes and `finish`'s `wrapping_mul(8)` past 2^61 bytes — but SHA-2's own message domain is < 2^64 bits (= 2^61 bytes), so within the spec's domain no input can trigger it; there is no explicit domain refusal for inputs beyond it (a 2-EiB "module" is not a realistic attack). Documented-note severity only. Confidence: HIGH — Verification: read.
