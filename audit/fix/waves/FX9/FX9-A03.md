# FX9-A03 — CLI session compositing lane — sidecar + embedded subtitle cues composite onto the presented frames

## Approach

The defect (REALITY-SCORE rows 057-059/064/068 UNREACHABLE; FIX-PLAN §5 F3.1
"Wire: CLI verbs + Frame::Subtitle render path"): `pipeline_host.rs` dropped
every `Frame::Subtitle` (`Frame::Subtitle(_) => Ok(())` at the audited :1567),
sidecar files had no session lane at all, and `accept_video` pushed the
converted RGBA frame with zero overlay compositing while the whole
compositing contract (`SubtitleCompositor` / `ComposeTarget` /
`CompositedCue`) sat unused. The fix builds the session subtitle limb as a
`SubtitleLane` (state at :1419) owned by the consumer: sidecar loads (srt /
vtt / ass text through the real dispatch and render paths, pgs `.sup` and
the vobsub `.idx`+`.sub` pair through the real parsers with bytes crafted
in-test) reduce to `Vec<CompositedCue>`; the embedded `Frame::Subtitle` arm
(`accept_subtitle_frame` :1674, routed at :2882) reconstructs A04's overlay
payloads onto the same compositor. Compositing happens after the
pixel-format conversion and before `scheduler.push` (~:3006-3012): under
`Stamp::Present(now)`, `state.subtitles.composite_onto(&mut uploadable, now)`
blends the cues active at the frame's OWN pts onto the RGBA rows — one
clock, the same timeline the scheduler holds the frame against, so the
presented-frame tap inherits the composited pixels by construction. The
`decoder_for` `"pgssub"` arm (:375) wires A04's `PgsSubtitleDecoder` so
embedded PGS-in-TS flows the same lane, and the six pre-agreed
`CliFrameConsumer` seam verbs (:2800-2859) give FX9-A01's dispatch/host
chain its live surface.

## Test design

Every oracle is pipeline-agnostic ink: ink = a pixel difference from the
same frame's no-lane baseline (`presented_frames(None)` vs
`presented_frames(Some(&fixture(...)))`), never a glyph shape — so the
assertions hold under the placeholder AND swash glyph pipelines alike
(the real-glyph pixel claims live in A02/A05's crate tests). The srt test
asserts the present schedule keys are identical with and without the
sidecar, then that frames inside `[CUE_START_NS, CUE_END_NS)` differ
(≥40 of them) while frames outside are byte-identical (≥10) — the no-cue
case leaves bytes untouched; a sibling pins the ink to the bottom band
(the default bottom-center anchor pulled inside by the 5 % title-safe
clamp). The vtt/ass tests run the real dispatch through the same oracle;
the pgs `.sup` and vobsub `.idx`+`.sub` tests craft display-set / SPU
bytes against the frame's own extent so placement is exact, and the
embedded test drives A04's real `PgsSubtitleDecoder` to a
`Frame::Subtitle` overlay payload that reconstructs and composites.
Determinism is asserted across runs of the composited presented frames;
the verb-chain test checks arrival truth through the `tracks.list`
snapshot (not the echoed request), and bad sidecar inputs assert the
typed refusals.

## Risks & followups

Seam-signature notes vs how host.rs calls it: the FX9-A01 row sketched
`subtitle_sidecar_tracks() -> Vec<TrackInfo>`; the implementation returns
`Vec<WireTrackInfo>`, which is exactly `TrackInfo as WireTrackInfo` — a
re-alias at pipeline_host.rs:82 of the commands-catalog wire type — so the
contracted shape is honored and host.rs's snapshot extension
`tracks.extend(consumer.subtitle_sidecar_tracks())` (:389) composes because
the rows ARE the wire `TrackInfo` the snapshot already carries (fields
`.id`, `.is_selected`). `CliHost::set_subtitle_track` (:1604) does the lane
split — a wire id naming a sidecar row drives the sidecar lane with the
engine's embedded lane deselected (`TrackSelector::None` + `subtitle_select_sidecar(Some(id))`), anything else drives the engine lane with the
sidecar lane deselected, embedded-lane-first so a refusal leaves the
sidecar untouched; the read-back is the sidecar's selected row, else the
engine mirror from `self.tracks`. `subtitle_add_file` (:1720) discards the
registration result (`let _ =` at :1727) — arrival truth comes only through
the snapshot, never the echoed registration. One residual risk: the
compose adapter's `Err(_) => 0` (~:1775-1780) swallows a compositor error
into "zero rows drawn" rather than a typed failure — a silent no-ink
instead of an honest refusal; followups are the central test run for this
suite plus A07's honest counting of the subtitle-row flips.
