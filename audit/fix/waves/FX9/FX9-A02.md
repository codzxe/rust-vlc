## Test design

`tests/fx9_a02_font_stack.rs` runs the REAL pipeline over the REAL
committed face via the public `subtitles::font` API only (swash is a
private dependency; the tests exercise the seam, which is the point of
the admission). Deterministic, no network/display; `testkit::Must` for
fixture contracts; assert/eq/ne only (deny lints). Each test carries
its audit-oracle citation in the header comment:

- `fx9_a02_bundled_face_loads` — the asset pins: family/format/
  size 759,720, swash parses the committed bytes (`SwashPipeline::new`
  `Some`), garbage bytes are the typed `None`. The size pin ties the
  committed file to the R11 provenance.
- `fx9_a02_session_pipeline_is_swash` — the session seam hands out the
  real stack (`name() == "swash-dejavu-sans"`), the placeholder's name
  as the negative control, live metrics at 64 px.
- `fx9_a02_session_stack_serves_bundled_default` — the A03 seam:
  "DejaVu Sans" resolves family-matched with the `"bundled"` trail; an
  unknown family falls back to the bundled face with the honest
  `family_matched: false` trail and the FauxBold/FauxItalic synthesis
  ledger.
- `fx9_a02_metrics_are_face_derived` — every probed size well-formed;
  metrics DIFFER from the placeholder's pinned 3/5-6/5-em ratios at 48
  and 64 px (whole-struct `assert_ne` + the advance field
  specifically); double-size scaling within 2 px; the seam's typed
  guards (zero / beyond-MAX / at-MAX) shared with the placeholder.
- `fx9_a02_advance_is_real_per_char` — `advance('i')` and
  `advance(' ')` are narrower than the nominal cell, `'i'` < `'W'`
  (DejaVu: ~0.32 em vs ~0.67 em vs the ~0.64-em cell); the default
  trait method's one-cell answer on both chars is the contrast
  (the A05 contract).
- `fx9_a02_masks_differ_per_char` — the F-001 oracle: 'i'/'o'/'W'
  masks all differ, 'i' narrower (box + ink column band); real
  anti-aliased coverage (a 255 core, a 1..=254 edge, row-0 empty —
  cap height < ascent); the placeholder's 'i' and 'W' masks are
  byte-identical 0-or-255 blocks as the negative control.
- `fx9_a02_descender_reaches_below_baseline` — 'g' descends (mask ≥
  ascent+6, real ink in the rows below the baseline row) while 'n'
  sits on it (≤ ascent+2) — baseline alignment of real ink.
- `fx9_a02_decorations_keep_real_geometry` — underline strip rows
  [ascent, ascent+strip) solid full width with the plain ink above
  the baseline UNTOUCHED (sample-exact vs the undecorated mask);
  strikeout centred on ascent/2 without growing the box; faux bold
  widens only and only adds coverage; faux italic shears wider,
  horizontal only; the overhang ledger's exact pinned ratios
  (0 / max(1, cell/6) / cell/4 / their sum).
- `fx9_a02_rasterize_is_total_over_degenerate_inputs` — the F-003
  hole closed: hand-built degenerate `GlyphMetrics` (the pub-field
  contract, including all-zero) × junk chars × all decorations
  produce well-formed, dimension-capped masks, never panics (the
  placeholder panicked here — the audit's open question #3 "fix before
  admission"); the junk-char totality list mirrors the placeholder
  suite's; a space carries no ink.

Robustness discipline (this sandbox runs no cargo — RULES.md): exact
assertions are used only where they follow from the implementation's
own integer formulas (overhang, strip rows) or the committed asset
(byte size); everything face-derived uses inequalities with margins
wider than any plausible metric-source variance (hhea vs OS/2: the
'i'-vs-cell gap is ~0.32 em, the g descender ~0.23 em, the
digit-vs-placeholder advance gap ~0.036 em at probe sizes where the
roundings cannot collide).
