## Test design

This crate has no local compile path in this sandbox (no webkit2gtk/gdk-sys;
the recorded baseline dies at gdk-sys before these sources are
type-checked), so the regression test for "the shipped GUI compiles" IS the
CI lane compile itself — per assignment, the lane id stands in for a rust
test: **ci.yml job `tauri-check`, step "Build the admission crate (lib + bin —
the real GUI binary)"** (`cargo build --manifest-path
apps/desktop-tauri/Cargo.toml --locked`, on ubuntu-latest with the
webkit2gtk-4.1 dev set installed by the lane). This step fails first — ahead
of `cargo test --all-targets` — on any E0425-class break (lib and bin alike
fail to resolve an undefined symbol). The lane also keeps the anti-bypass
test, clippy `-D warnings`, cargo-deny, and the ldd smoke. Local proofs
actually executed (rg, this session):
- `rg -n "spawn_session_pump" apps/desktop-tauri/` → **0 hits** (exit 1)
  after the fix — was exactly 1 (app.rs:301) before.
- `rg -n "fn spawn_event_pump" apps/desktop-tauri/src/app.rs` → **1 hit**
  (line 190).
- Call-site argument expression type matches the parameter (reasoned read of
  both sites, item 1 above).
- ci.yml YAML parsed cleanly post-edit; the tauri-check step list verified.
