# FX8-A01 — the status-truth generator (one status layer, from source)

## Approach

The prior session's design was lost with its sandbox; it was rebuilt from
the assignment and proven against its known-good values (14 decoder
families shipped / 18 verbs, 17 wired / 69 catalog commands, 20 wired) —
which this rebuild reproduces exactly, and every row is re-derivable by
rg against the same anchors REALITY-RESCORE §4 cites.

Truth is parsed FROM SOURCE, never docs, from exactly the three sources
named in the assignment plus the two files the "wired" booleans and the
fail-closed cross-checks require:

* **decoder families** — `apps/cli/src/pipeline_host.rs`: the codec
  arms of `HostDecoderProvider::decoder_for`'s match, cross-checked 1:1
  against `LANDED_DECODER_FAMILIES` (the registry FX2-A03 exported as
  data beside the match it mirrors). The catch-all (`other`/`cli.
  codec_unavailable`) must exist and be the last arm; a non-literal,
  non-`starts_with` guard arm, an attribute (conditional) arm, or a
  multi-line literal pattern is *unclassifiable* → exit 2.
* **host verbs** — `apps/cli/src/host.rs`: every `pub(crate) fn` (any
  indent) plus the module-level `pub fn` handlers (`engine_info`,
  `command_listings`). Plain `pub fn` *methods* (`settle`/`pump`/
  `track_snapshot`/…) are the host's plumbing/test surface, excluded by
  design — the catalog section carries the command surface they would
  duplicate. `wired` = the handler has a call site in the SHIPPED
  dispatch layer (`apps/cli/src/dispatch.rs`, cut at `#[cfg(test)]` —
  the single command entry ARCH-5). async/unsafe/const `pub fn` shapes
  and any public fn after the first `#[cfg(test)]` are unclassifiable →
  exit 2.
* **catalog commands** — `crates/commands/src/catalog/command.rs`: the
  `pub enum Command` variants (69), cross-checked 1:1 against the
  `CommandId` stable-id table in `crates/commands/src/catalog/ids.rs`
  (the emitted `id` column comes from that parse, never hand-mapped).
  `wired` = the variant is routed by a non-refusal arm of dispatch.rs's
  `route()` (comment-stripped, so a doc line cannot mint wiring), which
  must carry its catch-all `other =>` refusal; the routed set is
  cross-checked EQUAL to the `SERVED` table in the same file — a
  served-but-unrouted command (the silent-understatement hole) is a
  shape failure.

Fail-closed is the core property (FIX-PLAN P1: "the status layer that
drifted in both directions carries zero information; it gets replaced"):
**the generator never emits a quieter row when a shape changes — it
exits 2** (a missing file, an arm without a registry row or a row
without an arm, a routed/SERVED disagreement, an enum/id-table
mismatch, a `#[cfg]` conditional variant, an unclassifiable line each
name their file:line on stderr). The emitted TOML is self-validated
(re-parsed with `tomllib`, summary counts re-checked against the rows)
before stdout sees it. Python 3 stdlib only; no cargo anywhere.

Sibling contracts honored exactly: `.github/workflows/ci.yml` (FX8-A02)
runs `bash scripts/quality/status_truth_check.sh` — the gate is
CWD-independent and was run from outside the repo root, exit 0; the
demotions (FX8-A10) and the matrix sweep (FX8-A03) point at
`docs/generated/status-truth.toml`, whose header carries the exact
regen command and the never-hand-edit warning.

## Risks & followups

* Line anchors drift by construction: any edit above a parsed anchor
  changes the committed TOML and the gate goes red until regenerated —
  that is the design working (drift detection), not noise, but it means
  every PR touching the five parsed files must regenerate (one
  command, printed by the gate on failure).
* The route()/SERVED comment-strip cuts at `//`; a string literal
  containing `//` followed by a routed `Command::` on the same line
  inside route() would truncate that line — the routed/SERVED equality
  check then fails (exit 2, never understates) rather than emitting a
  wrong row.
* `host_verb.wired` means "wired through the dispatch layer"; a handler
  wired only by future non-dispatch call sites (e.g. run.rs bypassing
  ARCH-5) would show `false` — such a bypass would itself be an
  architecture violation the gate's sibling lanes should catch.
* FX8-A02's ci.yml lane is the missing piece this deliverable depends
  on (the gate exists and is proven; the workflow wiring is that
  sibling's row, in flight this same wave).
* No test files added by design (python/bash work; the assignment's
  DoD for this row is the generator + committed artifact + gate, with
  self-checks in prose — the `tests:` block is left empty
  accordingly).
