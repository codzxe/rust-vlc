## Per-artifact ledger

### 1. scripts/quality/w26_captures.sh (new) — the fail-loud regen harness

Four modes (usage/exit-2 contract printed by `bash
scripts/quality/w26_captures.sh` with no args):

- **`index-gate [--write]`** — the drift gate. Regenerates the committed
  INDEX (embedded python3-stdlib generator, deterministic: sorted output,
  no timestamps) from a fresh scan of `docs/waves/w26/**` (excluding the
  INDEX itself — a generated file never scans itself) and `diff -u`s it
  against the committed copy; exit 1 on drift with the diff and the regen
  command; `--write` regenerates in place (the regeneration command named
  in the INDEX header). Generator failure → exit 2 ("never understated"),
  same contract as FX8-A01's status-truth gate. Missing INDEX → drift,
  exit 1, regen command printed.
- **`capture [--out DIR] [--port N]`** — the regen. Probes FIRST (exit 1
  fail-loud if the UI stack is missing), then drives the committed tool
  `ui/scripts/dev-shots.mjs` over the 25-route truth parsed live from the
  `ROUTES` block of `ui/e2e/visual/manifest.ts`
  (`sed -n '/export const ROUTES/,/\] as const;/ s/^  "\(\/[a-z0-9/-]*\)",$/\1/p'`
  → exactly 25 routes; the initial unscoped sed also matched the 2
  ACCENT_SAMPLE_ROUTES — fixed to block-scoped), default
  `--out docs/waves/w26/captures/regen/` (in-tree, never /tmp-only).
  dev-shots' own exit 1 (console errors / unreachable routes) propagates
  — nothing swept under the rug. 0 routes parsed (manifest shape drift) →
  exit 2, refuses to guess.
- **`compare DIR_A [DIR_B]`** — the capture diff: md5 listing of every
  file in both dirs, `diff -u`; exit 0 only if the sets are
  byte-for-byte identical, exit 1 with the name/md5 diff otherwise; DIR_B
  defaults to the regen dir.
- **`probe`** — check-only: node on PATH, `ui/node_modules/playwright`
  present, dev server answering 200 on `:5173`; exit 1 with a remediation
  line per FAIL (`(cd ui && npm ci)`, `(cd ui && npm run dev)`).

Verification (all on the final script): `index-gate` → **exit 0**;
`probe` on this box (no `ui/node_modules`, :5173 refused → `000`) →
**exit 1**, two FAIL lines + remediation + "capture regen cannot run
honestly"; `capture` → **exit 1** (probe-first refusal); `compare` on two
identical synthetic sets → **exit 0**, on a byte-corrupted/extra-file set →
**exit 1** with the md5 diff, on a missing dir → loud FAIL. Drift path: a
/tmp copy of the harness + the whole `docs/waves/w26` tree ran green
(exit 0), then a seeded citation (`/tmp/fx8a06-drift-seed-2/late-probe.png`
+ `console-late.log` appended to `logs/w26.c1.md`) turned the gate **red,
exit 1** — the printed diff showed exactly the two new inventory rows —
and the `--write` → gate cycle went back to **exit 0**. One real bug was
found and fixed during this: the EXIT traps referenced `local` variables
(unbound at trap-fire under `set -u`, corrupting exit codes) — traps now
embed the mktemp path at set time.

### 5. tools/vta/vp9/evidence/compare_frames.py (new) — the per-frame comparator

The record §D method as an executable: per-frame MD5 of frame-sized
chunks both sides (`frame size = bps·(w·h + 2·⌈w/2⌉·⌈h/2⌉)`, bps=2 for
profile-2 10-bit) + a whole-stream MD5 cross-check; exit 0 only if every
frame is byte-identical AND the whole streams match; exit 1 with the
first differing frame index + digest pair; exit 2 on shape/usage errors
(byte totals with the expected arithmetic printed). python3 stdlib only,
no cargo. Self-tested: identical ffmpeg dumps → PASS exit 0 (whole-stream
MD5 printed == the record's lane A value); one corrupted byte → exit 1
("first differing frame 0" + digests); truncated file → exit 2 (byte
totals); missing args → exit 2. The 10-bit geometry was proven on lane F:
50 × 230,400 B = 11,520,000 B with MD5 2391b4241617d81cf05d50efd54781d4 ==
record.
