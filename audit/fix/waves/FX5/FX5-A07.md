# FX5-A07 — Engine-lane seek path verification (FIX-PLAN §3 F1.3, wave split)

## The trace (engine → wrapper → demuxer, with citations)

**Command → engine.** `playback.seek` → `host.rs:1079 dispatch_seek` →
`host.rs:1126-1128 handle.seek(request, engine_target)` (`SessionHandle::seek`).
The state row's `SeekPipeline` effect lands in `session.rs:1985
seek_pipeline_step`:

- step 1 semantic — `resolve_target` (seek.rs:273-304, clamping is truth);
  failure emits `EngineEventKind::SeekFailed{reason, position}` at
  session.rs:2005-2011;
- step 1 capability — session.rs:2018-2021 `pipeline.seekability() !=
  SeekSupport::None`, which is `pipeline.rs:1189-1190
  self.demuxer.seekability()` — i.e. the WRAPPER's forwarded answer;
- steps 3–4 — session.rs:2041-2044 `pipeline_seek` (seek.rs:369-412):
  `pipeline.seek_flush` (pipeline.rs:1239) then **`pipeline.demuxer_reanchor`**
  — `pipeline.rs:1498-1499 self.demuxer.reanchor(target)`, the ONLY
  `Demuxer::reanchor` call site in the engine (verified repo-wide with rg;
  every other hit is a wrapper impl, the demuxer crates' own tests, or the
  clock's unrelated same-named method).

**The object identity.** The demuxer the engine reanchors is the exact object
the host built: `host.rs:915 open_source` → `OpenedMedia.demuxer` →
`host.rs:972-978 SessionConfig::new(..., opened.demuxer, ...)` → engine open →

## What was broken and fixed

The executed S0 had exactly ONE broken link: `Mp4Demuxer::reanchor` was the
trait default — FX5-A01's row, and their implementation is now in-tree
(mp4/mod.rs:2086). **Nothing in this lane swallowed the demuxer's capability
or failed to call it** — the wrapper forwards seek/seekability/reanchor
verbatim (demux_host.rs:592-618), `StartedMp4` forwards (mp4.rs:167-178), and
the engine calls reanchor at pipeline.rs:1498-1499.

The gap the trace DID prove, and what I fixed: the seam was **untested**. The
demux_host.rs audit's per-function table claims `SelectDemuxer::reanchor`
(:606-618) is "test-pinned" — that claim is FALSE (an audit drift worth
recording): rg over apps/cli shows no test anywhere exercising demuxer
`reanchor` (the only test-shaped `.reanchor(` hits are the clock's unrelated
method in sync_scenarios.rs and the demux crates' own suites). Zero production
code was changed by this agent; the fix is the seam pinning below.
