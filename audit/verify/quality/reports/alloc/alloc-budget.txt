# Allocation amplification budget

Instrument: `tools/mem-audit` (already in-tree), run over real fixtures.

Naive `peak/size` is **not** the DoS metric - it is dominated by the fixed
per-open cost. Measured **K (fixed open cost) = 148960 B**, estimated as the
median peak of inputs <= 8 KB. The gate uses the scaling part:
`excess = max(0, peak - K) / size`, threshold **0.01x**.
A crafted header that makes allocation scale with input bytes is the
memory-exhaustion attack a panic-watching fuzzer never sees.
