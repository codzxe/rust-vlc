### Scaling decision (recorded per card 4.G2)

Doc 08 §6.1 asks for "every screen in §1.6 (~40 unique compositions) ×
{dark, light} × {default accent} at 1×; accents beyond default sampled
(onboarding + settings global ×9 accents)". Two honest reductions:

1. **Route set = every route that exists in `ui/src/App.tsx` today (15)**
   rather than §1.6's ~40 compositions — the remaining compositions
   (player.customize, miniplayer variants as states, context menus,
   audio/video tools, playlist/subtitles flow, settings second states) have

   doc-named routes, 8 non-default accents (the 9th, default, already
   covers every viewport × DPI × mode cell). Full accent × full grid would

## OS scope honesty + per-OS extension path

**This run is Linux-only** — the sandbox has no macOS/Windows runners, so
"3 OS" is infra-blocked (same gate precedent as other wave cards). The
honest AC subset achieved: the full route × viewport × DPI × mode × accent
matrix, green, on the canonical Linux set, with the multi-OS path ready:

- **Baseline sets are already per-OS**: `visual.spec.ts` resolves
  `baselines/<platform>/` (G1), so a macOS/Windows CI job (doc 08 §6.3:
  one dedicated job per OS) only needs to run
  `npm run visual -- --mode=nightly --update` once on that OS to pin its
  set, then verify without `--update` in CI. Linux stays canonical.
- **OS-text exceptions mechanism** (doc 08 §6.2 "platform font rendering
  differs"): the harness handles it at two levels —
  1. *within* a CI OS, the flakiness controls (§6.4: reduced-motion,
     fonts.ready, settle delay, #root clip, retries=1) plus bundled/pinned
     fonts make text rasterization stable enough for pixel diff at
     `threshold 0.1` + `0.001` ratio — no per-case exceptions needed on
     Linux (this run: zero);
  2. *across* OSes, differences land in the **per-OS baseline sets**, not
     in loosened tolerances — the tolerance file is shared, the pinned
     PNGs are not. A genuine cross-OS text nondeterminism that survives
     retries would be documented per-case here with a written reason
     before any tolerance change (Lead sign-off per §6.5); none arose.
