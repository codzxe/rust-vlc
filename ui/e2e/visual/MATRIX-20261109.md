## Addendum (same day, final stretch)

**Accent-default discrepancy (registered, not silently ignored):** the
manifest anchors the grid on `orange`, but the product default is **dark +
yellow** ("Solstice Keyvox gold") — ThemeProvider's initial state, the
tokens.css `:root` block, and the tokens.test.ts sha-pinned expectations
all agree; only a stale TS header comment in the generated tokens module
and the red `e2e/theme.spec.ts` claim orange. The re-pinned grid therefore
does **not** depict the out-of-box look; all 9 accents are still covered
(orange via the grid, yellow + 6 others via the samples). Deliberate
re-anchor (yellow → unsuffixed grid, orange → suffixed samples + full
re-capture) is the recorded follow-up; the manifest docstring carries the
same note. Related: `npm run test:e2e` is **32/38** — the 6 failures are
all in `e2e/theme.spec.ts`, which expects the orange-default token set
(plus stale yellow/gray hexes); that spec, `src/tokens/**`, and
`ThemeProvider` are identical between main `145b265` and this branch, so
the redness is inherited from main and outside this lane's ownership
(`ui/e2e/visual/**` + configs/workflow only).

**Aborted second capture pass:** a re-capture re-run died mid-flight,
leaving ~121 modified PNGs + a half-applied yellow→orange sample swap in
the worktree. PR-lane compare against the committed baselines passed
30/30 (57.8 s), proving the committed set correct, so the dirty files
were discarded (`git restore`); the worktree was verified back to exactly
136 tracked baselines, 0 dirty.

## OS scope honesty + per-OS extension path

**This run is Linux-only** — unchanged reality from MATRIX-20261024: the
repo's sandbox has no macOS/Windows runners. The multi-OS path stays as
issue #5 wired it in `.github/workflows/ui.yml`: the non-blocking
`visual-baseline-seed` job (schedule/dispatch, `continue-on-error`)
runs `--mode=nightly --update` on `windows-latest`/`macos-latest` and
uploads the captured set for human review + commit. Until those per-OS
sets are committed, a compare run on those OSes fails by design (missing
baselines) — honest, not fake green. macOS/Windows therefore remain
**CI-blocked on a first real seed run**; this document's numbers describe
only the Linux canonical set.
